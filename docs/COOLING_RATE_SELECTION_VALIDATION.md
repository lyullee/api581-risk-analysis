# 냉각수 흐름도: 처리수 상한·재질 명목값·실측 우선

기준: 제공된 API RP581 제3판(2016), Part2 Annex2.B §11.1.10,
§11.3.2.2 및 Figure2.B.11.1(PDF401,404,414).
흐름도 페이지 이미지를 직접 확인했다.

독립 Python API5개 (`api581.api.damage`):

| 함수 | 계산 |
|---|---|
| `cooling_water_treatment_bounds` | 처리수 일반·피팅의 엄격한 상한 |
| `cooling_water_other_material_estimate` | 탄소강/저합금강 외 재질의 명목0.5mpy |
| `cooling_water_measured_rate` | 대표 실측값과 쿠폰 일반/국부 변환 |
| `cooling_water_rate_selection` | 실측 우선 후 명시적 처리수/담수/해수/기타재질 경로 |
| `cooling_water_selected_thinning` | 선택 부식률에서 감육DF, 선택 근거/상한 표지 보존 |

원문 흐름도의0.5mpy는 처리된 폐회로가 아니라
“탄소강 또는 저합금강인가?”의 No 분기이다.
기타 재질 정량 SCC·피팅·탈합금 모델이 있다는 뜻은 아니다.
적합한 내식성 재질의 명목 추정과 다른 열화기구 평가를 확인한 경우에만
0.5mpy=0.0000127m/year를 반환한다. 재질명만으로 자동 적용하지 않는다.

처리수 분기는 일반부식<3mpy, 피팅<15mpy이다.
각각0.0000762·0.000381m/year를 `strictly_less_than` 상한으로 반환하며
실측값이나 정확한 예측값으로 반환하지 않는다.
유효 처리 프로그램·MIC 제어·침전/국부 저유속 부재·pH6.5–9.5와 근거를 요구한다.
흐름도는 일회통과 담수도 처리 분기로 보낼 수 있지만 상세 본문은 살생물제 외 약품처리를
가정하지 않는다고 한다. 일회통과 처리수는 `qualified_figure_treatment` 해석을 명시해야 한다.
순환계에 이 해석 필드를 잘못 입력하는 경우도 거부한다.

상한에서 실제 감육 계산에 넣을 값은 별도 명시적 정책이다.

- `screen_at_strict_upper_bound`: 엄격한 상한과 같은 수치를 보수적 검토값으로 사용한다.
  실제 부식률이 그 값이라는 주장 대신 `selected_rate_is_screening_bound=True`를 결과와DF에 유지한다.
- `qualified_rate_below_bound`: 소유자 근거가 있는 수치를 입력하며 반드시 원문 상한보다 작아야 한다.
  상한과 동일하거나 큰 수치를 원문의 처리수 추정으로 위장하지 않는다.

원문 흐름도 첫 분기는 쿠폰 또는 유사 실측 결과가 있으면 측정값을 사용한다.
이 구현은 적격 실측값이 있으면 대체 모델을 실행하지 않는다.
0은 유효한 실측값으로 보존한다. 실측값의 대표성이 부족하거나 일반/국부 구분이
평가와 맞지 않으면 조용히 모델로 교체하지 않고 오류를 반환한다.
쿠폰의 중량손실 일반부식률에서 국부 평가를 할 때만 명시적5–10배 계수를 요구한다.
이미 국부 측정된 값에 피팅 계수를 다시 곱하지 않는다.
일반 쿠폰을 일반 평가에 사용하는 경우도 배수를 추가하지 않는다.
대체 모델의 입력 구조는 여전히 타입 검증을 받지만 실측값 우선 시 모델의 계산·적용성 분기는 실행하지 않는다.

실측이 없으면 `fallback.kind`로 처리수/담수/해수/기타재질을 선택한다.
자동 수질·재질·약품처리 분류는 하지 않는다.
기존 담수·해수 정량 모델은 탄소강 범위를 유지하며,
처리수의 탄소강/저합금강과 기타재질 명목 분기는 별도로 일치 검사를 한다.
측정값 대표성·분포·검사 범위와 모든 적용 가능한 손상기구는 사용자가 확인해야 한다.

그림에는 RSI식2.B.7·최종 부식률식2.B.5라는 번호도 보이지만
상세 본문은 각각2.B.10·2.B.8이다. 잘못된 번호로 다른 식을 실행하지 않으며
공식 정오표가 있다는 주장도 하지 않는다.

신규35개 테스트: 처리수의 엄격한 상한, 일회통과 해석,0.5mpy의 실제 재질 분기,
실측0·우선순위·모델 미실행, 대표성·일반/국부·쿠폰 배수,
상한 동등값/초과값의 거부와 보수적 검토 표지,
담수·해수 독립 함수와 일치 및 선택 부식률→감육DF 일치를 확인했다.
전체1403개 테스트 통과. 타입·스키마·wheel 별도 설치 검증을 함께 수행한다.

예제: `examples/cooling_rate_selection_to_thinning.py`.
미완료: 실제 약품처리 효과·측정 대표성·MIC/침전물의 현장 판정,
기타 재질의 SCC/탈합금 정량 모델과 자동 적용성 검토,
공식 모호 셀 해소·모든 손상기구와 전체 설비 위험의 자동 통합.
