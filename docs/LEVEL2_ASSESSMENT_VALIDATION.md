# Level2 사건·기구·재정 위험 집계 검증

기준: 제공된 API RP581 제3판(2016), Part3 §§5.8.7–5.12,
식3.176–179,3.188,3.191,3.198–204(PDF559–573쪽).
최종식3.202–204는 원본 페이지 렌더링과 직접 대조했다.

## 공개 함수

`api581.api.level2`의6개 독립 함수는 다음 경계를 제공한다.

| 함수 | 입력→출력 |
| --- | --- |
| `flammable_case` | 한 누출공의5개 사건 면적·확률→가연성 면적 |
| `scenario_consequence` | 위 사건·선택 독성 면적·NFNT 원래 면적→분리한 기구 면적 |
| `final_area` | 이미 가중한 기구 면적→식3.202–204 |
| `consequence_summary` | 네 누출공의 이미 사건 가중한 기구 면적→기구별 GFF 평균·최종식 |
| `scenario_summary` | 네 누출공의 원래 사건/독성/NFNT 입력→최종식 |
| `assessment` | 위 시나리오·부품형식·공급 DF·재정 가정→GFF/Fms·면적·재정피해·연간 위험 |

모든 함수는 정적 타입 입력·결과 모델과 공통 출처·제한사항·코드 지문을 제공한다.
기존 Level1 API의 결합식은 변경하지 않았다.

## 사건 확률과 공유 비점화 경로

pool_fire,jet_fire,fireball,vce,flash_fire를 각각 하나씩 명시한다.
적용하지 않는 사건도 확률·면적0으로 명시하며5개 사건·선택적 상관 제트/풀 분기·비점화 확률의 합은1이다.
상관 분기는 연속2상 누설의 즉시점화에만 적용하고 별도 제트/풀 사건은0으로 둔다.
`docs/TWO_PHASE_EVENT_VALIDATION.md`에 최대 면적의 단일 확률 가중을 기록했다.
입력은 사건 발생 조건부 **가중 전 면적**이며 원문 식3.176–177대로 합산한다.
제트는 연속 방출에, 기본 파이어볼 기준은 순간 파열에만 양수 확률·면적을 허용한다.
그림5.3 순간 누설 파이어볼을 선택하려면 `fireball_applicability_basis=figure53_instantaneous`를 명시한다.
이는 본문과 그림의 불일치를 자동으로 숨기지 않기 위한 별도 선택이다.
증기/액체/2상 사건 트리 자체는 입력 근거와 함께 공급한다. 현재 자동 추론하지 않는다.

독성·NFNT는 같은 비점화 확률을 사용한다.
독성은 성분별 선택 기준의 면적 최대를, NFNT는 물리폭발/BLEVE/증기·화학 피해의
적용 가능한 최대를 고른 뒤 각각 비점화 확률을 한 번 곱한다.
독성 성분 목록을 생략하려면 `toxic_applicability=not_applicable`과 근거가 필요하다.
목록이 있는데 비적용으로 표시하거나, 평가한다고 표시하고 목록이 없으면 거부한다.

## 최종식은 Level1과 다르다

§5.11.1의 일반 설명은 기구 최대를 언급하지만 구체적인 인쇄 식3.202–203에는 가연성 기여의
**가산**이 있다. 이 구현은 구체적인 식을 따른다. safe 사건의 피해면적은0이다.

`CA_equipment = CA_flammable_equipment + CA_nfnt_equipment`

`CA_personnel = CA_flammable_personnel + max(CA_toxic_personnel, CA_nfnt_personnel)`

`CA = max(CA_equipment, CA_personnel)`

따라서 화재·독성·NFNT 면적 전체의 최댓값만 택하는 Level1 함수를 재사용하지 않는다.
서로 같은 비점화 경로에 속한 독성·NFNT를 더하지도 않는다.
예를 들어 가연성 인체200,독성500,NFNT300이면 인체 결과는700이다.

## GFF 평균의 순서

식3.178–179,3.191,3.200–201에 따라 각각의 기구 면적을 GFF로 평균한 뒤
최종식의 비점화 최대를 선택한다. 네 누출공은small,medium,large,rupture가 각각 하나씩 필요하다.
전체 GFF는 양수이며 DF 보정 빈도를 평균의 가중치로 대신 사용하지 않는다.

두 유효 누출공의 GFF가 같고 가연성 인체 면적이각10이라고 하자.
독성은100/0,NFNT는0/100이면 각각의 가중 면적은50/50이며 최종 인체는60이다.
누출공별 최대를 먼저 구하면110이 되어 원문의 순서와 달라진다.
이 반례를 테스트에 포함했다.

## 종합 위험평가의 경계

`assessment`는 `component_type`의 표 GFF를 사용한다. 재정 수리·정지기간의 부품형식도 같아야 한다.
각 기구 평균과 최종 면적을 계산한 후 §5.12의 지시에 따라 §4.12의5재정 항목을 재사용한다.
입력 재정 모델에는 면적 필드가 없어 내부 계산 면적을 다른 값으로 덮어쓸 수 없다.
가격·통화 변환·가격 기준연도·인구밀도·공급/차단 관련 가정·유출 정화량은 사용자가 확정한다.

GFF합계에 공통 DF·Fms를 적용해 연간 실패빈도를 구하고 부품 수준 결과에 곱한다.
결과는 재정위험(통화/년),설비·인체 면적 위험(m²/년)을 포함한다.
DF0이면 면적·재정피해는 유지되고 연간 위험은0이다.
같은 부품의 공통 DF/Fms 모델이며 누출공별 DF가 다른 평가를 이 평균으로 대체하지 않는다.

통합 범위는 `supplied_level2_event_probabilities_areas_and_damage`이다.
현재 자동 손상 적용성, 전체 플래시/EOS, 실제 확산,2상 사건 트리, 미래 손상 예측을 포함하지 않는다.
통합 함수가 있다는 사실을 전체 자산자료 자동 평가 완료로 표현하지 않는다.

## 검증과 예제

`tests/test_level2_summary.py`는 수동 계산한5사건 수치·확률 보존·제트/파이어볼 적용성,
Level1/2 차이·기구 평균의 비가환 반례·독성 생략·NFNT 최대와 비점화 가중,
수동4공 가중·기존 재정 함수 대조·연간 위험 단위·DF0·부품 일치·넘침을 확인한다.

`examples/level2_risk_assessment.py`는 이상기체 누출의 제트 열복사와 파열 파이어볼,
공급 구름 질량/면적의 VCE/플래시화재,기체 저장 에너지의 물리폭발을 계산한다.
이 면적과 공급 독성 발자국·DF·재정 가정을 통합 API에 전달한다.
사건확률은 후속 점화 API로 인화점·유량·명시한 온도 기준·표5.3에서 계산한다.
구름 질량·발자국·인화점/물성·온도 기준·가격은 예제 가정이며 실제 확산 결과나 설치 검증 값이 아니다.

이 검증은 코드의 식·순서·통합 계약을 확인한 것이며 전체 규격·실험·LH2 적용성 인증을 뜻하지 않는다.
