# 미점화 풀 증발·정상 소스항 검증

기준: 제공된 API RP581 제3판(2016), Part3 §5.7.4,
식3.103–105(PDF544쪽), 표5.2M(PDF582쪽), Annex3.B C14·C15(PDF647쪽),
기호표(PDF578–579쪽). 식과 환산상수는 원본 페이지 렌더링과 대조했다.

## 독립 Python 경계

`properties.pool_surface_interaction`은4종 지표면의 W/(m·K),m²/s,무차원 거칠기 값을 반환한다.
SI 표를 직접 사용하며 US 반올림 표를 역환산해 대체하지 않는다.
`release.pool_evaporation_regime`은 Tb<Tg 비등,Tb>Tg 비비등으로 판정한다.
같은 온도는 원문에 규칙이 없어 경계 상태를 반환하고 두 유량 모델은 등호를 자동으로 포함하지 않는다.

화재의 연소율은 기존 `effects.pool_burning_rate` 범위다.
이 모듈은 즉시 점화되지 않은 풀에서 확산·VCE·플래시화재의 원료가 될 증기를 계산한다.

## 비등 풀의 원문 식

`E=pi^1.5 * [X*k*(Tg-Tb)/(C14*Hv*sqrt(pi*alpha))] * sqrt(2*g*Vdot) * tp`

`r=sqrt(2/3)*(8*g*Vdot/pi)^.25*tp^.75`

C14는SI에서1이며 E는kg/s,Hv는J/kg,k는W/(m·K),alpha는m²/s다.
식 첫 항은 **pi^1.5**이며1.5라는 상수가 아니다.
Vdot는 기호표가 정의한 **풀 표면을 떠나는 증기의 체적유량(m³/s)**이다.
액체 유입 질량유량을 액체 밀도로 나눈 값을 대신 넣지 않는다.
tp도 기호표상 정상상태에 도달하는 시간이며 임의 경과시간으로 해석한 동적 질량수지를 주장하지 않는다.

원문 설명대로 정상상태에서 E=유입 액체 질량유량이므로
Vdot=유입유량/풀 증기밀도로 구하고 첫 식에서 tp를 역산한 후 반경을 계산한다.
증기밀도는 풀 표면의 대기 방출 조건으로 사용자가 확정한다. 저장 조건 밀도를 자동으로 재사용하지 않는다.

## 비비등 풀의 원문 식과 C15

`E=C15 * [Pb,g*MW/(R*Ts)] * u^.78 * r^1.89`

인쇄된 C15=4.685,Pb,g는kPa,MW는kg/kmol,R=8314J/(kmol·K),Ts는저장 온도K다.
공개 압력Pa는 식에 넣기 전에1000으로 나눈다. 따라서 SI 공기측 포화밀도
`Pb_Pa*MW/(8314*Ts)`에 대한 수치 계수는.004685에 해당한다.
Pa를 그대로 C15=4.685와 곱하면 증발량이1000배 달라진다.

본문은 초기 과도 후 액체가 지표면 온도에 가까워진다고 설명하지만 분모에는 Ts를 인쇄한다.
현재는 인쇄된 저장 Ts를 사용하고 이를 지표면 온도로 조용히 바꾸지 않는다.
지표면 온도에서의 버블점 압력Pb,g는 별도 물성 입력이며 대기압보다 작아야 한다.
풍속은 원문 기준인 지상6ft에서 사용자가 확정한 값이다. 높이를 자동 환산하지 않는다.

정상반경은 E=유입유량 조건으로 역산한다. 이 식에는 정상 도달시간이 없어 시간을 추정해 넣지 않는다.
풍속 또는 버블점 압력0에서 유입이 양수면 이 상관식의 유한 평형 반경이 없다.
0풍속의 증발률0은 분자확산·자연대류까지 포함한 무증발을 뜻하지 않는다.

## 지원 조건과 반환 상태

정상 소스 함수는 계산상 평형과 실제 사용 가능성을 구분한다.
비등은 공급 지속시간이 tp보다 길고 평형 면적이 부지 제한 이하여야 `supported`다.
공급이 tp와 정확히 같은 순간에 끝나도 지속 정상 소스로 취급하지 않는다.
비비등은 평형 반경/면적이 유한하고 면적 제한을 만족해야 한다.
이 함수만으로 비비등 정상상태의 시간상 성립을 검증한 것은 아니다.

비등의 제한 상태는 `duration_limited`,`area_limited`,`duration_and_area_limited`이다.
비비등은 `area_limited` 또는 `no_finite_steady_state`를 사용한다.
평형을 지원하지 않으면 `vapor_source_rate_kg_s=None`이며 원래 평형 값은 별도 출력으로 남긴다.
지원하는 양의 유입에서는 사용 가능 정상 소스가 유입유량이다.
유입0은 `no_feed`,사용 가능 소스0이며 tp는None이다.

면적을 임의로 잘라 원문 평형을 유지한 것처럼 표시하지 않는다.
`supported`는 이 함수의 필요한 수학적/공급/면적 조건을 만족한다는 뜻이며 현장 검증 상태가 아니다.
재고 소진·성장·유출·배수·공급 중단 후 잔류풀·지면의 냉각 변화는 별도 모델이 필요하다.

## 검증

`tests/test_evaporation.py`는 다음을 확인한다.

- SI 표4행과π지수·체적유량·반경의 수치 앵커.
- 비등 평형 유량의 원문식 재구성,증기밀도·유입량의 시간/반경 스케일링.
- 비등 공급시간·부지 면적의 단독/동시 제한과 정확한 시간 경계.
- 비비등의 압력kPa·저장 온도·풍속/반경 지수.
- 독립적인 US 상관식(C15=1,P psia,R1545,T°R,풍속/반경ft,유량lb/s)과 SI 결과의 대조.
  인쇄 반올림 계수를 고려해 상대오차.002 이내로 확인한다.
- 비비등 역산을 독립 이분법과 비교하고 원래 식으로 유량을 재구성한다.
- 잘못된 온도/압력 영역,영 풍속·영 증기압·영 유입과 유한 평형 부재.

`examples/pool_vapor_sources.py`는 지원되는 두 평형과 지원되지 않는 한 사례를 실행한다.
물성은 가정한 값이며 실제 slabx 실행·동적 풀 모델·EOS/플래시·현장/LH2 실험 검증은 포함하지 않는다.
