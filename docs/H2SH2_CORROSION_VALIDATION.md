# 고온 H₂S/H₂ 부식률과 감육 검증

기준: 제공된 API RP 581 제3판(2016), Part 2 Annex 2.B §4,
Tables 4.1–4.7M, Figure 4.1(PDF 353–363쪽), Table 1.2(PDF 323쪽).
표·흐름도를 렌더링 확인했다. 독립 공학 인증을 의미하지 않는다.

`api581.api.damage`의 독립 함수:

| 함수 | 역할 |
|---|---|
| h2sh2_table_axes | 재질군·단위별 온도/몰분율 축 |
| h2sh2_table_rate | H₂S·온도와 나프타/가스오일 표 조회 |
| h2sh2_corrosion_assessment | 수소 황화 환경·재질·스트림의 적격 통합 평가 |
| h2sh2_thinning_assessment | 동일 부식률의 적격 무클래딩 감육 DF |

입력 H₂S는 기상 몰분율이다. 원문0.002mole%=0.00002몰분율=20ppmv다.
질량분율·부분압·황 함량으로 대체하지 않는다. 온도 K, 부식률 m/year다.
표는20ppmv–1mole%와 SI218–524°C/US425–975°F를 다룬다.
본문의 통상204°C 이상이라는 설명으로204–218°C 공백을 채우거나 저농도 부식률을0으로 만들지 않는다.
SI/US 온도·부식률 반올림을 보존하며 표 밖 외삽은 거부한다.

6표군·16명시 재질을 제공한다. 탄소강/원문 저합금6종,5Cr,7Cr,9Cr은
나프타/가스오일 두 곡선,12Cr과304/304L/316/316L/321/347은 곡선 구분이 없다.
물리 셀 수는4표군×8농도×2곡선×12온도×2단위+2표군×8농도×12온도×2단위=1920개다.
나프타/가스오일은 공정 분류이며 통상 비점430°F 설명을 최고 운전온도와 단순 비교하지 않는다.
12Cr/스테인리스에는 사용하지 않는 스트림 입력을 거부한다.
원문에 없는 재질이나 연속 Cr 함량으로 표를 보간하지 않는다.

무탄화수소 기상의 부식률이 최대50% 높을 수 있지만 같은 상관식이 RBI에 적합하다는 본문에 따라,
추가1.5를 자동 곱하지 않는다. 낮은Cr 표에서는 적용할 원문 곡선과 적격 근거를 명시하고 표지를 남긴다.
보간은 정확 노드/선형 농도·온도 bilinear/주변 최대값 중 명시적으로 선택한다.
원문 상관식의 로그 보간을 임의 재구성하지 않는다.

통합 평가는 수소 황화 환경의 적격 확인을 요구한다.
황과 수소의 존재만으로 촉매에 의한 H₂S 전환이나 다른 기구의 적용성을 판정하지 않는다.
감육은 같은 부식률과 전용 `high_temperature_h2s_h2` 모니터링 행을 사용한다.
원문 일반부식 분류와 실제 검사 분포의 적격 근거를 별도로 보존한다.
서비스 없음의0은 이 기구에 한정하며 전체 감육 DF0을 뜻하지 않는다.

신규 테스트1944개 중1920개는 모든 전사 셀의 공개 조회·단위 변환 확인이다.
런타임 표와 fixture는 같은 `scripts/extract_h2sh2_source_fixture.py` 추출 경로를 공유하므로
셀 테스트만으로 전사 정확성을 독립 입증하지 않는다. 전사는 렌더링 검토에 근거하며,
독립 기대값으로 농도 단위·보간·공유 재질·무탄화수소 분기와 감육 조합을 검증했다.
fixture에는 PDF SHA-256·셀 출처 페이지를 기록하고 `_h2sh2_tables.py`는 코드 지문에 포함된다.

[예제](../examples/h2sh2_to_thinning.py):5Cr-0.5Mo,기상H₂S0.3mole%,413°C,가스오일에서
1.85mm/year,20mm 초기 벽두께·2년의 손실분율0.185를 확인한다.

별도 HTHA·습윤 H₂S 균열을 포함한 모든 손상기구의 자동 위험 통합.
