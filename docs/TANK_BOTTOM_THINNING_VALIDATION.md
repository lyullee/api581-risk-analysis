# AST 바닥 감육 손상계수와 위험 연결

기준은 제공된 API RP581 제3판(2016) Part2 §4.5.5–4.5.7이다.
PDF153 식(2.12)과 PDF163 표4.7을 이미지로 확인했다.
AST 바닥은 비압력 판 요소이므로 기존 압력용기 `damage.thinning_unclad`로 대체하지 않는다.

`api581.api.tank`에 다음 독립 Python API8개를 추가했다.

| 함수 | 역할 |
|---|---|
| `bottom_minimum_thickness` | RPB 유무의 원문 최소두께 또는 문서화된 소유자 방법 |
| `bottom_wall_parameter` | 잔여두께와 식(2.12)의 Art |
| `bottom_inspection_selection` | 적격 검사 중 최상위 효과 등급을 최대1회 인정 |
| `bottom_thinning_base` | 표4.7 전체105개 셀과 명시적 구간 사이 처리 |
| `bottom_thinning_adjustment_factors` | 용접/리벳, 유지관리, 침하 계수 |
| `bottom_thinning_assessment` | 외부 순부식률부터 AST 전용 감육DF |
| `bottom_corrosion_thinning_assessment` | 양면 부식률부터 동일 요청의 감육DF |
| `bottom_corrosion_risk_assessment` | 양면 부식률·감육DF·소스·피해·연간 재정위험 |

식과 적용 범위:

- 원문 기본 최소두께는 RPB 없음0.1in=0.00254m, 있음0.05in=0.00127m이다.
  문서화된 소유자 별도 방법은 값과 근거를 함께 입력한다.
  현재 API653의 설계/검사 수락기준을 자동 판정하는 기능은 아니다.
- 잔여두께는 시작두께−부식률×경과시간이다.
  Art=max(1−잔여두께/(최소두께+부식여유),0)이다.
  이는 손실량/시작두께인 비AST 식(2.13)과 다르다.
  시작두께와 경과시간은 같은 검사 또는 설치 기준일에서 출발해야 한다.
- 표4.7은 Art0–1, 간격0.05, 검사 E/D/C/B/A이다.
  본문 STEP13은 표4.8을 지칭하지만 실제4.8은 온라인 모니터링 표이다.
  이 구현은 실제 AST 표4.7을 사용한다.
- 원문은 표 행 사이의 보간 방법을 명시하지 않는다.
  `exact_rows_only`, `linear_between_rows`, `conservative_upper_row` 중 수치 처리 정책을
  필수 선택하며 임의의 원문 요구사항이라고 주장하지 않는다.
  Art>1은 표 범위 초과 오류로 반환하고 최종행에 묶거나 외삽하지 않는다.
  원시 Art 함수는 음의 잔여두께와 관통 예측도 진단용으로 보존한다.
- §4.5.6에 따라 AST 바닥의 검사 크레딧은 최대1회이다.
  입력은 평가기간 내 적용 가능한 검사이며 이력 중 최상위 등급1회 선택은 구현 정책이다.
  검사횟수 누적·베이지안 업그레이드·과거 기준일 이전 검사 자동 인정은 없다.
  실제 검사 효과의 Annex2.C.5 분류와 두께 기준 갱신은 소유자가 확인해야 한다.
- 용접1/리벳10, API653 유지관리1/그 외5,
  침하 초과2/충족1/미평가1.5/콘크리트 무침하1을 적용한다.
  AST 바닥은 배관 주입점·데드레그 계수1이며 모니터링은 표4.8의 기타부식기구 계수1이다.
  최종DF=max(기본DF×용접계수×유지관리계수×침하계수,0.1)이다.
- 통합 부식률 계산은 이미 토양측 부식을 포함한다. 같은 외면손실의 DF를 다시 더하지 않는다.
  부식률·최소두께·누출 소스의 RPB 유무가 다르면 계산을 거부한다.
- 위험 통합은 다른 손상기구의 배제 근거가 있는 `qualified_thinning_only` 범위이다.
  동일 요청에서 계산한 감육DF를 외부 DF 재입력 없이 기존 소스/환경·수리·생산손실에 연결한다.
  연간빈도=공별 GFF합×감육DF×관리계수이며,
  연간 재정위험=연간빈도×이미 GFF가중된 재정피해이다.

검증: 신규60개 테스트에서 표105개 셀, 기준 최소두께/별도 방법,
식의 음수 잔여두께·하한, 검사 최대1회, 보간 정책·외삽 거부,
모든 AST 보정계수, 잘못된 기준/수치, RPB 불일치,
독립 함수 조합과 통합 DF·위험의 일치를 확인했다. 전체1156개 테스트 통과.

현장 부식률/검사/침하 검증, 라이닝·코팅 보호기간, 가변 부식 이력,
자동 검사계획/FFS, 다른 손상기구의 자동 적용성 판단과 전체 탱크 위험은 미완료다.
숫자 예제는 인증이나 실제 설비 수락 판정의 근거가 아니다.
호출 예제: `examples/tank_bottom_corrosion_to_risk.py`.
