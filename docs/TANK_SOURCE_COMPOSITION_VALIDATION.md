# AST 치수·토양·소스·위험 연결

API RP581 2016 Part3 §§6.1–6.7, Tables6.1M–6.5(PDF592–598,604–607)를 기준으로 한다.
누출공 표는 페이지 이미지와 대조했다. 텍스트 추출에서 파열 대표지름의 분모4가 누락되므로
이미지의 d4=1000·(D_tank/4)mm를 사용한다. US표의12·(D_tank/4)inch와 일치한다.

## 독립 함수

| 함수 | 범위 |
|---|---|
| shell_hole_sizes | small3.175mm,medium6.35mm,large50.8mm,rupture D/4 |
| bottom_hole_sizes | small RPB있음3.175mm/없음12.7mm,medium/large0,rupture D/4 |
| shell_source_assessment | 대표 유체·공 선정·코스 하단 수두/재고·유량·탐지·공별 방출 부피/질량 |
| bottom_source_assessment | 유체·토양·물 기준물성→전도도/침투·공 수·전체 재고·유량·탐지·방출 |
| bottom_integrated_assessment | 바닥 소스→지하수 도달→환경/수리/생산손실→외부 DF 기반 연간 위험 |

SI Table6.4M은 파열에서 RPB Yes만 표시한다. 완전한 US Table6.4의 Yes/No 공유 D/4공식을
No-RPB에도 적용하며 이 근거를 제한사항에 기록한다. 공식 SI 정오표라는 주장은 하지 않는다.
표6.5는 바닥 small/medium/large 개수만 제공한다. 파열 유량·질량유량·검지시간·지속시간은 null이며
식3.230에 따라 전체 재고를 방출량으로 반환한다. 이를 0유량으로 해석하면 안 된다.

쉘은 STEP3.3에 따라 네 공 모두 식3.209의 명목 유량을 계산한다. D/4 파열공의 상수수두 결과는
실제 파열 과도 수력의 검증을 뜻하지 않는다. 파열 부피는 코스 하단 위 전체 재고이고 지속시간은 null이다.
누출공별 방출은 독립적인 대안 시나리오이므로 합한 부피가 재고를 넘을 수 있다.
각 공의 부피는 개별 재고 한도를 지킨다.

## 해석 선택과 단위

기존 독립 탱크 API와 같은 기준을 사용한다.
대표유체7종의 밀도/점도는 운전온도 EOS가 아니다. 물의 밀도·점도 기준은 필수 입력이다.
수리전도도는 m/day, 유량은 bbl/day와 kg/s, 부피는 bbl와m3, 질량은kg다.
원문 C13=6.29를 유지하며 mass=Bbl 인쇄식을 kg로 쓰지 않는다.

쉘 탐지시간3.17mm/3.175mm 경계, 바닥 전이식 공 수 누락, RPB/콘크리트 기초 탐지 우선순위는
필수 선택 또는 조건부 필수 선택으로 전달한다. 빈 탱크는 RPB 수두 치환으로 가짜 유출을 만들지 않는다.
바닥 공 수 공식의 표 밖 지름은 표시한다. 원문의 SI/US C37 구간 차이는 해결했다고 주장하지 않는다.

각 소스의 GFF는 표3.1 공별 값이며 식3.208 합계를 사용한다. 인쇄 총합도 별도 보존한다.
하나의 바닥/코스를 다루며 전체 탱크 코스를 곱하거나 공통원인을 자동 합산하지 않는다.

## 통합 바닥 평가

치수·토양에서 계산한 같은 재고·유량·공별 부피·탐지시간·침투속도로 환경피해를 구성한다.
호출자가 서로 다른 방출량이나 중복된 GFF를 추가 입력하지 않는다.
손상계수와 관리점수·가격의 적합성은 외부 입력이다. Table6.6 가격 기준연도는 원문에 없으므로
환경 단가와 수리비 물가/환율계수를 같은 선언 가격 기준으로 맞춰야 한다.
소스에서 면적을 자동 생성하지 않으며 바닥 평가에 정의되지 않은 면적0을 반환하지 않는다.

## 검증

추가19개 테스트: 누출공 표·D/4면적·수두/재고·쉘 유량의 독립식,
3.17mm 경계와 빈 코스, 기존 바닥 수치 앵커, 공 수·전이식 선택·RPB·영 재고,
null 파열유량, 수치범위 오류, 개별 소스→지하수→재정 위험과 통합 결과의 일치를 검사했다.
전체897개 회귀 테스트 통과. `examples/tank_geometry_to_risk.py`에서 전체 바닥 연결을 실행한다.

동적 배수, 실제유체, 현장 지하수/토양 이질성, 자동 손상 적용성·미래 DF,
쉘 화재/독성 면적의 자동 생성·방유제 풀 면적 제한, 실제 slabx/slabx-lh2와 현장/LH2 검증은 남아 있다.
