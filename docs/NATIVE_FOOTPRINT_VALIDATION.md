# 평면 농도장·기준 초과 면적·플래시화재

API581 Part3 §5.8.6/§5.9에서 외부 확산 모델의 공간 면적을 받는 경계를 구현한다.
추가한 삼각형 격자 적분은 명시적 수치 후처리이며 인쇄된 API581 상관식이 아니다.

## 독립 격자 면적

`dispersion.threshold_grid_area`는 x/y 좌표와 농도[crosswind][downwind], 공통 기준과 표본 근거를 받는다.
좌표는 음수/비균일을 허용하되 유한하고 엄격히 증가해야 한다. 농도는 volume fraction0–1이다.
최대100만 노드로 제한한다. 단일 높이·시간평균·소스/기상 기준의 평면이다.

각 사각형을 좌하→우상 대각선으로 나눠 삼각형 위 농도를 선형 보간한다.
기준 이상인 다각형을 클리핑하여 면적을 적분한다. 국소 단위 사각형 좌표를 사용해
큰 전역 좌표의 평행이동에 따른 shoelace 소거 오차를 피한다.
이는 지정한 보간 함수의 면적이며 실제 연속 농도장의 정확한 면적이라는 주장은 하지 않는다.

어느 격자 가장자리에서든 기준 이상이면 boundary_censored이며 threshold_area_m2는null이다.
sampled_exceedance_area_m2는 격자 내부에 계산한 진단 면적이다.
전체 표본이 기준 미만이면 not_reached와면적0이다. 표본 사이에 놓친 최대점이 없다는 의미는 아니다.
도달은 했으나 모든 가장자리가 기준 미만이면 closed_on_supplied_grid로 표시한다.
공급 격자에서 닫힘은 실험/현장 적합성이나 전체 수치 수렴의 증명이 아니다.

## 실제 native 평면장

`dispersion.native_pool_footprint`는 선택 설치한 SLABx1.0.8/LH2 0.2.0의 같은 풀 계산에서
ConcentrationField.at_y를 호출한다. native x격자와 지정한 대칭 y격자를 사용하며
Crosswind 좌표·실제 농도 행렬·보간 면적·노드수·경계 상태를 반환한다.
기존 중심선 모델의 유한 증기 풀·정상 비등점·101325Pa·명시적 물성/평균시간 등의 제약을 유지한다.
native 소스 확장, x_max와최종 puff 범위 차이, 엔진/코드 지문도 보존한다.

중심선 거리와평면 면적은 별개다. 중심선 역산이 성공해도 횡방향 범위가 부족하면 면적은null일 수 있다.
LH2 전제 위반도 면적을null로 만든다. 원시 평면장과 진단 적분은 실패 이유 분석용으로 남긴다.
기본 SLABx 적용성은not_evaluated, LH2 전제 통과도 현장 적합성 검증을 뜻하지 않는다.
중심선 거리를 원형 면적으로 치환하거나 안전계수를 자동 적용하지 않는다.

## 플래시화재 연결

`dispersion.native_pool_flash_fire`는 criterion_role=qualified_lfl을 필수로 받는다.
이 선언과threshold_source가 물질별 LFL, 평균시간, 모델 적합성의 실제 검증을 대신하지 않는다.
사용 가능한 LFL면적을 기존 effects.flash_fire에 전달해 인체면적=A,설비면적=.25A로 계산한다.
점화확률·GFF를 추가 가중하지 않으므로 상위 사건/장비 집계에서 한 번만 가중해야 한다.
경계 검열/전제 위반으로 유효 면적이null이면 dispersion_footprint_unusable로 실패한다.
그 경우0 또는 진단 면적을 정상 피해면적으로 반환하지 않는다.

## 수치·실제 엔진 검증

추가20개 테스트로 반평면의 정확 면적, 닫힌6각형, 균일 임계 plateau, 미도달,
독립 가우시안 해의 면적과격자 수렴, 전역 좌표 평행이동/축척 불변성,
좌표·행렬 형상·수치 범위와 native 격자 한계·사용 불가 면적의 플래시 연결 차단을 검증했다.
가우시안 기준 면적은2πσxσy ln(Cmax/Cthreshold)이며 엔진/삼각형 구현을 복제한 앵커가 아니다.
전체 회귀 테스트949개 통과.

선택 엔진이 설치된 환경에서는 `scripts/verify_native_footprint.py`를 별도로 실행했다.

- Native at_y 직접 호출과 어댑터 농도 배열의 정확한 일치, 횡대칭.
- 같은 native x격자에서 y129→257노드 세분화에 따른 면적 변화.
- 좁은 y범위의 경계 검열과 플래시 연결 거부.
- 실제 native LFL면적→설비 .25배/인체1배 매핑.
- LH2 실제 평면장과 낮은 풍속 전제 위반의 면적 사용 차단.

예제 baseline 면적91257.5680m2,횡세분화 후91246.7808m2,상대차이0.011822%였다.
같은 LH2 예제 면적은17.1216m2였다. 물성·기상·기준은 명시한 시험 입력이다.
이 횡격자 비교는 native x격자/실제 모델 전체의 오차 추정이나 현장 안전면적의 검증이 아니다.

위 baseline 평면 예제 높이는1m다. 후속 원문 대조에 따라 전용 native_pool_flash_fire는 높이0m를 요구하며,
실제 검증 스크립트도0m 평면과 플래시화재를 별도로 비교한다. 일반 footprint의 높이 선택은 유지한다.

임의 제트·소스 시간 이력·EOS·과도 풀·3차원 구름 질량 적분·독성 기준 자동 생성,
다중 풍향/사건의 공간 합집합과 개별/사회적 위험·현장/LH2 적용성은 남아 있다.
