# AST 쉘 방유제·사건·면적·위험 연결

API RP581 2016 Part3 §6.5–6.11(PDF596,598), §6.12.2(PDF599–600)를 기준으로 한다.
공개 함수는 `api581.api.tank`, 구현은 `src/api581/tank_shell.py`다.

## 방유제 풀 계산

§6.7.2는 pool fire area가 방유제 면적을 넘지 않는다고 쓰지만 연소 풀과 복사 피해면적을 구별하지 않는다.
`diked_pool_consequence`는 dike_limit_basis를 필수로 받는다.

- burning_pool_area: 연소 풀의 최대 면적을 방유제와 별도 site limit 중 작은 값으로 정한다. 그 형상에서 복사를 계산하며 피해면적은 방유제 밖까지 갈 수 있다.
- burning_and_consequence_area: 위 과정에 더해 최종 설비·인체 피해면적의 수치를 방유제 면적으로 제한한다.

두 기준은 명시적 원문 해석이며 공식 정오나 실험 검증을 뜻하지 않는다.
후자는 다각형 방유제와 원형 복사 영역의 공간 교집합 계산도 아니다.
unclipped_* 면적·거리는 같은 복사 모델의 제한 전 결과다. status는 그 복사 역산의 상태이며,
수치 제한된 최종 면적의 경계와 같다는 주장을 하지 않는다. *_area_clipped로 실제 제한 여부를 구분한다.
풀 형상/거리 원문의 기존 모호함과 명시적 선택, 단일 풀 모델의 적용성 제한도 그대로 유지한다.

## AST 사건별·4공 집계

`shell_level2_case`는 일반 Level2 사건 계산을 AST 조건으로 제한한다.
방출 형식은 파열을 포함해 continuous다. 다섯 사건(pool/jet/fireball/VCE/flash)을 모두 명시하며
비적용 fireball의 확률·면적은0이어야 한다. 전체 확률은 비점화와 합하여1이다.
연속 누설의 상관 제트/풀 분기는 기존 max(jet,pool)를 같은 확률로 한 번만 가중한다.
독성은 성분 최대 면적에 같은 비점화 확률을 한 번 적용한다. 빈 성분은 not_applicable과 근거를 요구한다.

AST §6.10은 NFNT를 계산하지 않으므로 NFNT 입력을 받지 않는다.
출력의 nfnt_status=not_determined_for_ast는 NFNT 피해를 계산해서0으로 얻었다는 의미가 아니다.
제공된 연소 풀은 방유제보다 작아야 하고,0풀에는 양의 풀 복사 면적을 허용하지 않는다.
피해면적도 제한하는 기준이면 상관 분기의 풀 면적까지 방유제 제한을 검사한다.

`shell_level2_summary`는 같은 방유제 면적/해석의 네 공을 정확히 한 번씩 받는다.
표3.1 COURSE-1-10의 공별 GFF와 식3.208 합계를 사용한다.
가연성 설비·인체·독성 인체를 각각 GFF 평균한 뒤,
설비=가연성 설비, 인체=가연성 인체+독성 인체로 집계한다.
§6.11이 지정하는 Level2 식3.202–3.204의 NFNT 비적용 형태이며 Level1의 단순 최대 선택으로 대체하지 않는다.
이 함수는 이미 사건 가중한 원시 면적에 사건 확률을 다시 적용하지 않는다.

## 쉘 통합 평가

`shell_integrated_assessment`는 같은 치수·대표유체의 소스에서 재고·공별 유량/방출량·GFF를 계산하고,
외부 사건 면적을 가중하여 재정피해와 연간 위험에 넣는다.
빈 코스는 모든 원시 가연성·독성·상관 면적과 연소 풀 면적이0이어야 한다.
빈 코스의 물리적 면적·환경피해0이어도 표의 누설 수리/정지 비용과 외부 DF에 따른 재정위험은 남을 수 있다.

확률·원시 면적이 이 소스에 적합한지는 호출자가 근거로 보장해야 한다.
요청 모델이 같다는 사실만으로 EOS, 실제 확산, 모든 사건의 적용성이나 공간적 정합성이 입증되지 않는다.
단일 쉘 코스이며 전체 탱크 코스 간 중첩·공통원인·개별/사회적 위험을 자동 계산하지 않는다.

## 검증

추가17개 테스트로 방유제/부지 면적 제한 전후 풀 형상·복사 역산 보존, 빈 풀,
독성·가연성 수동 가중 앵커, GFF 평균 후 합산, NFNT/순간 방출/파이어볼 거부,
상관 제트/풀, 방유제 기준 불일치, 빈 코스, 독립 소스→면적→재정위험과 통합 결과의 일치를 검사했다.
전체 회귀 테스트914개 통과.

예제 `examples/tank_shell_source_to_risk.py`는 같은 소스에서 공별 풀 화재를 계산해 통합 평가에 연결한다.
풀만 점화0.2/비점화0.8, 독성 비적용, 플래시 없는 액체 풀 공급, 열역학·가격·DF는 명시적 예제 가정이다.
전체 물질 위험이나 API 점화식이 자동으로 그 확률을 산정했다는 의미가 아니다.
자동 점화/독성 기준·전 사건 생성, 실제 slabx/slabx-lh2, 현장/LH2 적용성은 미완료다.
