# 고온 산화 부식률과 일반 감육

기준: 제공된 API RP581 제3판(2016), Part2 Annex2.B Table1.1·§9,
PDF322,389–392. 표9.2/9.2M·9.3/9.3M을 이미지로 확인했다.
독립 Python API5개 (`api581.api.damage`)를 추가했다.

| 함수 | 역할 |
|---|---|
| `oxidation_screen` | 산소와 최대 금속온도의 스크리닝 |
| `oxidation_table_row` | 온도·부식률·미제공 셀을 보존한 재질 전체 행 |
| `oxidation_rate` | 명시적 표 해석에 따른 재질·온도 부식률 |
| `oxidation_assessment` | 적격 노출조건 확인 후 일반 산화율 |
| `oxidation_thinning_assessment` | 동일 부식률에서 비AST 무클래딩 감육DF |

표는 탄소강,1¼Cr,2¼Cr,5Cr,7Cr,9Cr,12Cr,304SS,309SS,310SS/HK,800H/HP의11행이다.
310SS/HK·800H/HP는 원문이 묶어 제시한 분류이며 임의 합금에 확장하지 않는다.
Cr 함량 사이의 연속 보간이나 실제 재질명 자동 매핑은 없다.
24개 온도 열×11재질×SI/US=528위치 중 수치318개와 대시210개를 보존한다.
SI 온도496–1135°C와US925–2075°F는 반올림 때문에 정확히 일치하지 않으며
SI mm/year 값과US mpy 환산값도 다르다. 입력의 `unit_basis`를 명시한다.

대시는 0 부식률·서비스 허용한계·재질 파괴온도라는 뜻으로 해석하지 않는다.
행 조회에서는 `None`, 정량 조회에서는 미제공 오류다.
대시를 지나는 보간과 최고온도 밖 외삽도 거부한다.
두 페이지 표를 이어 붙일 때도 양쪽 셀이 모두 존재할 때만 보간한다.
원문에 보간 지시가 없으므로 정확한 셀만/선형/상위 온도 셀의 수치정책을 명시한다.

Annex Table1.1은 산소 존재 AND 금속온도≥482°C(900°F)를 스크린으로 사용한다.
482°C와 정확한900°F는 다르므로 스크리닝 기준도 명시한다.
§9.1은 탄소강 산화 시작이 대략482°C이고 합금은 더 높은 온도라고 설명한다.
스크리닝을 통과했다는 것이 재질별 실제 시작온도나 현장 산화율 검증을 의미하지 않는다.
스크린 미충족은 독립 함수에서 조건 미충족을 반환하며 통합 정량 계산은 오류다.
임의0 부식률로 바꾸지 않는다.

스크린482°C/900°F와 첫 표496°C/925°F 사이에는 부식률이 제시되지 않는다.
기본은 거부이고, 근거가 있는 첫 셀 추정값을 명시적으로 선택할 수 있다.
`first_node_value_used`로 원문 정확한 행이 아님을 표시한다.
이 정책은 낮은 온도에서 산화가 없다는 가정이 아니다.

사용 온도는 최대 노출 **금속온도**이며 유체 평균온도가 아니다.
원문은 가열로 튜브에서 튜브 금속온도가 제어값이라고 명시한다.
한 표면·일정 기준기간의 일반 산화 감육을 계산하며 반대면 손실이나
상온 대기부식/CUI의DF를 중복하여 자동 추가하지 않는다.
강도비 식(2.17)/(2.18)의 응력·유동응력·최소두께는 지배 설계온도에서 적합해야 한다.
실온 강도나 코드 최소두께를 자동 생성하지 않는다.

모니터링은 표4.8의 기타 기구 행만 허용한다.
표 계수는1이며 주1의 근거 있는 경험 대체는 계속 가능하다.
HCl 등 액상 부식의 높은 모니터링 계수를 산화에 빌려 쓰지 않는다.
검사 효과·표면/두께 기준일·수명은 소유자가 확인해야 한다.
크리프·열피로·반복 박리·침탄/황화·재질 서비스 적합성·FFS는 별도 평가 대상이다.
