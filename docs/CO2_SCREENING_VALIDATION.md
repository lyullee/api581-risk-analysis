# CO₂ 흐름도 스크리닝과 입력 준비

기준: 제공된 API RP581 제3판(2016), Part2 Annex2.B Table13.1,
식2.B.35, Figure13.1(PDF425,427,429). 흐름도는 페이지 이미지로 대조했다.
독립 Python API7개를 추가했다.

| 함수 | 역할 |
|---|---|
| `properties.co2_partial_pressure` | 절대 전체압×CO₂ 몰분율 |
| `damage.co2_reynolds_mass_flow` | 질량유량·면적에서 질량플럭스/Re |
| `damage.co2_material_screen` | 재질 표 또는 Cr13% 흐름도 정책 |
| `damage.co2_hydrocarbon_wetting_screen` | 액체HC·수분20%·유속1m/s 분기 |
| `damage.co2_moisture_screen` | 자유수 증거·이슬점 불확실성·습윤 기본가정 |
| `damage.co2_screened_assessment` | 위 분기에서 동일 CO₂ 부식 모델로 연결 |
| `damage.co2_screened_thinning` | 스크리닝 결과·가정 표지를 보존한 감육DF |

부분압 입력은 절대Pa와 몰분율0–1이다. mole%·게이지압으로 자동 해석하지 않는다.
질량유량형 Re는 mass_flow×diameter/(area×viscosity)이다.
원문은 dotted m을 mass flux라고 부르면서 식에서는 면적으로 나눈다.
이 API는 kg/s 질량유량과 kg/m²/s 플럭스를 구분하여 이미 정규화된 플럭스를 면적으로 다시 나누지 않는다.
직경·유로면적·유효 점도와 다상 물성은 외부 적격 자료다.

재질 정책:

- 표13.1 정책은 탄소강/저합금강을 평가하고 스테인리스/구리합금을 CO₂ 저항성으로 가정한다.
- 그림13.1 정책은 탄소강 또는 Cr<13%이다. Cr=13%는 원문의 저항성 가정 분기이다.
  Cr 경계는 적격 철계 재질에만 적용하며 구리합금의 Cr0을 이유로 감수성 강재로 취급하지 않는다.
- 재질명이 없거나 선택한 해석이 다루지 않는 재질은 `not_covered`이다.
  이를0 부식률로 자동 바꾸지 않는다.
- 저Cr 스테인리스가 그림 기준으로 평가 대상이 되어도 기존 정량 모델의 저합금강으로 조용히 재분류하지 않는다.
  현재 정량 커널의 이름 있는 탄소강/저합금강 범위 밖이면 통합 계산을 거부한다.

탄화수소 습윤 분기:

- 액체 탄화수소 존재 AND 수분<20% AND 유속>1m/s일 때만 원문의 면제 분기이다.
  수분20% 또는 유속1m/s는 수분/이슬점 확인으로 진행한다.
- 그림은 수분%의 정확한 질량/부피 기준을 지정하지 않는다.
  적격 액체계 water-cut 정의와 근거를 받으며 가스 물중량분율·글리콜 조성을 대신 넣지 않는다.
- 액체계 수분이 알려지지 않은 경우 표13.1의30% 기본값은 명시적으로 선택한다.
  기본값은 면제 분기를 만들지 않으며 사용 여부를 반환한다.
- 이 분기는 원문의 단순화된 규칙이지 실제 금속이 유상으로 젖어 있다는 다상유동 검증은 아니다.

수분·이슬점:

- 적격 자유수 존재/부재를 직접 입력하거나, 이슬점과 사용자가 검토한 불확실성을 입력한다.
- 현재 온도가 이슬점 불확실성 구간 아래면 자유수 존재, 위면 부재이다.
  구간 내부와 양 끝은 `indeterminate`이며 통합 계산은 자동으로 부식률0을 반환하지 않는다.
- 불확실성이0이고 두 온도가 정확히 같을 때 그림의엄격한< 해석은 부재,
  대안 정책은 포화점 미확정으로 남긴다. 둘 중 하나를 명시적으로 선택한다.
- 수분 정보가 없는 가스계는 표의 습윤 기본가정을 명시적으로 선택할 수 있다.
  `free_water_assumed_from_missing_data`를 최종DF에도 보존하며 실제 관측과 구분한다.
- 근사 이슬점식2.B.25가 ±10°F 안의 정확도를 보장하지 못한다는 경고는 계속 유효하다.
  이 출력으로 불확실성0을 자동 설정하지 않는다.

통합은 재질→탄화수소→수분→기존 습윤 부식 모델 순서다.
면제된 분기에는 사용하지 않는 하위 모델 입력을 허용하지 않아 상충 근거를 숨기지 않는다.
부분압·온도·알려진 유속은 스크린과 계산에서 일치해야 한다.
각 면제의0은 CO₂ 특이 부식률이며, 다른 부식/SCC 면역이나 총DF0을 뜻하지 않는다.
감육 계산의 강도·불확실성·0.1 하한은 계속 적용된다.

신규45개 테스트: 부분압·질량유량/Re 동등성,
재질표·Cr13% 경계 양옆, 수분20%/유속1m/s 경계 양옆,
기본30%·습윤 가정, 이슬점 구간/동일온도 정책,
미확정·상충 자료·범위 밖 재질의 거부, 독립 습윤 커널 일치,
동일 부식률에서 감육DF 및 CO₂ 특이0과DF 하한 구분을 확인했다.
전체1498개 테스트 통과. 현장 검증 또는 원문 전체 구현 완료를 뜻하지 않는다.

예제: `examples/co2_screened_to_thinning.py`.
미완료: 실제 재질 조성/상태 확인·자유수/금속 습윤·다상/EOS 검증,
미지원 재질의 정량 모델·센서 불확실성 자동 결정,
다른 손상기구와 모든 설비의 자동 위험 통합 및 현장 적용성 검증.
