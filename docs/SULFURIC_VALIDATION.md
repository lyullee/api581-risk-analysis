# 황산 부식률과 감육 검증

기준: 제공된 API RP 581 제3판(2016), Part 2 Annex 2.B §5,
Tables 5.1–5.7M, Figure 5.1(PDF 363–373쪽), Table 1.2(PDF 323쪽).
표·흐름도를 렌더링하여 확인했다. 독립 공학 인증을 의미하지 않는다.

`api581.api.damage`의 독립 Python API:

| 함수 | 역할 |
|---|---|
| sulfuric_table_axes | 재질·단위별 농도/온도/유속 축 |
| sulfuric_table_rate | 명시적 단위·문제 셀 정책의 3축 부식률 조회 |
| sulfuric_thinning_classification | 일반/국부 분류와 원문 경계 정책 |
| sulfuric_corrosion_assessment | 적격 표/전문가 부식률과 동일 조건 분류 |
| sulfuric_thinning_assessment | 같은 부식률의 무클래딩 감육 DF 연결 |

농도는 황산 질량분율, 온도 K, 유속 m/s, 부식률 m/year다.
탄소강·304·316·Alloy20·C-276·B-2의 SI/US 표1776셀을 제공한다.
탄소강792셀, 스테인리스432셀, Alloy20 264셀, C-276 192셀, B-2 96셀이다.
정확 노드/3축 선형 보간/주변 최대값은 명시적 수치 정책이다.
농도별 비단조성을 보존하며 농도·온도·유속의 표 밖 외삽은 거부한다.

원문 불일치와 적용 제한:

- 탄소강 SI 표는 유속 m/s 제목 아래 US와 같은0/1/2/3/4.5/6.5/8.5/11.5/12를 적었다.
  기본 거부하며, 적격 근거로 인쇄 m/s 또는 대응 US ft/s 헤더 해석을 선택한다.
  결과에 선택한 해석을 남기며 공식 정정으로 단정하지 않는다.
- 304의75wt%, 중간 온도, 최고 유속 셀은 US99mpy/SI2.51mm/year다.
  주변999셀에 맞춰 수정하지 않는다. 해당 셀을 포함하는 조회·보간은 기본 거부하고,
  근거를 제공한 원문값 사용에 문제 셀 표지를 남긴다.
- Alloy20의 SI70°C와 US163.5°F도 그대로 보존한다. 단위 변환 오차로 자동 보정하지 않는다.
- 원문999mpy/25.37mm/year는 수치와 사용 표지로 남긴다. 무한대·결측 의미를 만들지 않는다.
- B-2는 산화제 없음이 명시된 경우만 표를 사용한다. 산화제 있음/불명은 거부한다.
  그림이 지시하는 전문가 추정은 별도 `qualified_specialist_rate`로 출처와 적용 근거를 받는다.
  다른 재질 표에도 산화제 개선 계수를 만들지 않는다.
- 탄소강 표의 난류 국부부식 증폭은 이미 반영되어 있다. 추가3배를 곱하지 않는다.
  실제 부식률이 추정치의20–50%일 수 있다는 본문 설명은 자동 할인계수가 아니다.
  표는 원문의 최대 추정값이며 모든 조건에서 보장되는 상한을 의미하지 않는다.

일반/국부 분류와 모니터링 분류는 다른 표를 따른다.
개요는 CS/SS/고합금의2/4/6ft/s(인쇄SI0.61/1.22/1.83m/s), 상세 탄소강 본문은
약0.91m/s, 모니터링 Table4.8은3/5/7ft/s를 사용한다.
분류 API는 개요 SI/US 또는 상세 탄소강 SI를 구분하고 정확한 경계는 명시적 정책과 근거를 받는다.
감육 연결은 **같은 물리 유속과 재질군**을 사용하면서 서로 다른 표의 임계값을 보존한다.
실제 검사 범위와 일반/국부 분포 적격 근거는 별도다.

원문에는100wt% 황산도 있어 자유수 없음→0 경로를 만들지 않았다.
황산 서비스 자체가 없다는 적격 확인만 기구 특이 부식률0을 반환한다.
이0은 전체 감육 DF0 또는 다른 손상기구의 부재를 뜻하지 않는다.

신규 테스트1796개 중1776개는 모든 전사 셀의 공개 조회·단위 변환 확인이다.
런타임 표와 fixture는 `scripts/extract_sulfuric_source_fixture.py`의 같은 추출 절차로 생성된다.
따라서 셀 테스트만으로 전사 정확성을 독립 입증하지 않는다. 렌더링 확인을 별도로 수행했고,
독립 기대값으로 3축 보간·원문 문제 셀·단위 해석·조건 일치와 감육 조합을 검증했다.
fixture에 원문 PDF SHA-256을 기록하고, 런타임 `_sulfuric_tables.py`는 코드 지문에 포함된다.
원문의 OCR 공백 소수점·소수 쉼표는 렌더링에 따라 정규화했다.

[호출 예제](../examples/sulfuric_to_thinning.py)는 316,98wt%,40°C,0.61m/s에서
0.38mm/year를 사용하고20mm 초기 벽두께·2년의 손실분율0.038을 확인한다.
탄소강 SI 유속 해석을 명시한 별도 독립 호출도 포함했다.
