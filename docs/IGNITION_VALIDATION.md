# Level2 점화·조건부 확률·그림 트리 검증

제공된 API RP581 제3판(2016), Part3 §5.8.1 식3.106–127(PDF546–550),
표5.3(PDF583),그림5.3/5.4(PDF586–587),Annex C4B/C5/C12/C16(PDF647–648)을 기준으로 한다.
점화 다항식·2상 가중식·온도상수·트리 그림은 원본 렌더링과 대조했다.

## 독립 계산

`release.flammable_phase_rates`는 식3.106–108의 전체 가연성 rate와플래시 분율의 액체/증기 rate를 구한다.
이는 rainout 후 풀/제트 분할과 다르다.
`events.ambient_ignition`은 액체/증기별 식3.109–110을 계산한다.
`ait_ignition_maximum`,`probability_temperature`,`conditional_table`,`two_phase_probability`는
나머지 단계의 독립 입력·출력 모델을 제공한다.
`single_phase_tree`는 조건부 확률을 그림 경로에 곱하며 `single_phase_ignition`이 전체를 조합한다.

## 인화점·유량 다항식

원문의8계수를 사용한다. 인화점K에C12=1.8을 곱해Rankine으로 사용하고,
rate는C5=25.2kg/s에서 제한한 후C4B=2.205로 lb/s에 대응시켜 자연로그에 넣는다.
인접 설명의25.22와 달리 인쇄 환산표의25.2를 선택하고 결과에 평가 유량·상한 적용을 보고한다.
0rate는 로그의 극한값0확률을 반환한다.

주어진 인화점에서 rate 지수가 양수인지,상관식 확률이1이하인지 검사한다.
1을 넘는 곡선을 조용히1로제한하지 않는다. 입력 근거 문자열은 실험적 적합성 인증을 대신하지 않는다.
인화점은 외부 자료/물성 입력이며 수소처럼 정의·적용성 확인이 필요한 경우 값을 자동 생성하지 않는다.

## AIT와명시적 온도 기준

액체의 AIT 최대 확률은1이다. 증기는 식3.112의 MW보간으로2에서.9,170이상에서.7이다.
이는 경험적 방출 점화 확률이며 결정론적인 자동점화 물리 모델이 아니다.

인쇄 C16은 **30.89K**, US는**70R**이다. 이 둘은 직접 변환으로도 일치하지 않고
주변의 ‘상온’·70F 설명과도 맞지 않는다. 이를 임의로294.26K로고치지 않는다.

- `api581_printed_c16`:30.89K를 그대로 사용한다.
- `qualified_reference`:사용자가 온도와근거를 명시한다. 공식 정오표로 주장하지 않는다.

Ts와기준 사이의 아래쪽 외삽은 거부하고 AIT<=기준도거부한다.
기준–AIT 사이는 선형 보간하고 AIT이상은 AIT한계를 사용한다.
‘최대’가 기준 확률보다 작으면 거부한다.
즉시점화도 같은 온도 가중을 표5.3의기준값과AIT값1사이에 적용한다.
전체 공급rate0일 때는 AIT이상이라도 조합의 점화확률0이며 비점화 확률1이다.

## 조건부 표·2상 가중

표5.3의 즉시점화 기준값은 연속 액체.2/증기.5,순간 액체.2/증기.1이다.
지연 후 VCE는 각각.25/.5/.125/.25이며 플래시는 여사건이다.
이 값은 무조건부 사건확률이 아니므로 지연점화 경로를 다시 곱해야 한다.

식3.115·118·119·122는 인쇄상 액체 확률에flash_fraction을 곱한다.
증기 플래시 분율이라는 설명과의 차이를 숨기지 않기 위해
`api581_printed_liquid_weight`와별도근거의`qualified_vapor_weight`를 구별한다.
후자는 공인 정오표가 아니다. 서로 같은 조건부 의미를 가진 액체/증기 확률만 섞어야 한다.

## 그림 트리와본문의 차이

지연경로 VCE=점화×(1−즉시)×VCE조건부확률,
플래시=점화×(1−즉시)×(1−VCE조건부확률)이다.
식3.125의 VCE 예시는 여사건을 곱하지만 그림5.3은 위와같다. 이 구현은 그림의 경로를 따른다.
모든 결과는5개 가연성 사건의0확률 경로를 포함하며 비점화까지 더해1이다.
비점화가 무조건 안전을 뜻하지 않으므로 독성/NFNT 후처리를 생략하지 않는다.

액체 즉시점화는 pool,연속 증기 누설은 jet,순간 증기는 fireball 경로다.
그림5.3은 **순간 누설** 증기의 즉시 경로도 fireball로표시하지만 본문§5.8.1.5는 파열을 설명한다.
새 트리는 이 경우 `fireball_applicability_basis=figure53_instantaneous`를 보고한다.
Level2 면적 모델도 같은 선택을 명시해야 이를 수용한다. 기존 기본 기준은 파열 전용 본문을 유지한다.
양수 화재면적의 실제 적용성까지 트리 선택이 자동으로 증명하는 것은 아니다.

현재 파열 그림은 순간 방출만 지원한다. 연속 파열은 경로를 임의로 만들지 않고 거부한다.
2상 조건부 가중을 조합한 트리와그림5.3의상관된max(jet,pool) 분기는 후속 구현으로 추가했다.
`docs/TWO_PHASE_EVENT_VALIDATION.md`에 하나의 사건 확률·최대 면적·통합 평가 연결을 기록했다.

## 검증·위험 예제

`tests/test_ignition.py`는70자리 Decimal의계수 직접 합산8조건,유량 상한,
AIT/MW·표4행,온도 경계/기준 선택,2상 기준 차이,단일상6경로·확률 보존,
그림5.3 선택과면적 API 연결,영 공급의AIT이상 처리를 검증한다.

`examples/level2_risk_assessment.py`는 기체 오리피스·가연성 rate에서 점화·즉시·지연·최종 사건확률을 계산한다.
인화점·AIT·기준온도·물성은 예제 가정이다. 명시적70F기준 선택은 공인 C16정정이 아니다.
그 확률과계산 화재/폭압면적·공급 구름자료를 기존 Level2 재정위험 조합에 전달한다.
실제 확산·경험 확률의 현장/LH2 검증·완전자산 자동평가를 완료한 것은 아니다.
