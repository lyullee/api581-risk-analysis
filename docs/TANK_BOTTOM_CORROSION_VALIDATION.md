# AST 바닥 양면 부식률 검증

기준: 제공된 API RP581 제3판(2016), Part2 Annex2.B §14.3, PDF430–436.
식(2.B.37),(2.B.38)과 표14.5–14.12는 페이지 이미지로 교차 확인했다.
원문 파일은 수정하거나 배포 패키지에 포함하지 않는다.

12개 독립 Python 함수는 `api581.api.tank`에서 정적 입력·출력 타입과 함께 제공한다.
기준 부식률, 토양 비저항, 패드, 배수, CP, 바닥 형식, 공통 온도, 제품 습윤,
스팀코일, 정기 물빼기, 양면 합성, 통합 부식률을 개별 호출할 수 있다.
통합 함수도 동일한 개별 계산을 재사용한다. HTTP·프론트 의존성은 없다.

토양측은 기준 부식률×비저항×패드×배수×CP×바닥형식×온도이다.
제품측은 기준 부식률×습윤×온도×스팀코일×물빼기이다.
토양측은 국부부식이며 제품측이 일반부식이면 두 값을 더하고 국부부식이면 최대값을 취한다.
예제의 토양측 0.0783354 mm/year, 제품측 0.1106875 mm/year는 일반부식 합성 시
0.1890229 mm/year가 된다. 이 계산은 부식률이며 아직 AST 감육 손상계수가 아니다.

원문 해석과 입력 경계:

- 기준 부식률은 토양측 0.13 mm/year 또는5mpy, 제품측0.05 mm/year 또는2mpy이다.
  반올림된 SI/US 쌍의 차이를 보존하고 기준을 필수 선택한다.
  실제 비교 가능한 검사 기반 기준 부식률이 우선이다. 이미 보정된 실측 순부식률에 보정을 다시 적용하면 중복된다.
- 비저항은 공개 입력Ωm, 원문Ωcm이다. 1000/2000Ωcm 공유 경계는 구간 선택이 필요하다.
  고비저항 AST 계수는0.66이며 매설 배관 계수0.60과 다르다.
  RPB가 있거나 비저항이 알려지지 않았으면 원문에 따라1을 쓴다.
- CP 표의 명목1/0.66/0.33과 실제 적용계수를 함께 반환한다.
  §14.3.1(d)의 High Level 검사로 효과가 확인되지 않으면 적용계수1이다.
  검증됨 입력에는 검사 근거가 필요하며 CP 부재와 검증됨의 모순은 거부한다.
- 온도 표의 SI24/66/93/121°C와 US75/150/200/250°F는 정확한 환산 시 다르다.
  기준을 명시하고 각 경계 이하 행을 적용한다. 최고 경계 초과 계수1도 원문 그대로 보존한다.
- 물빼기 저감0.7은 주1회 또는 매 입고 후 실시할 때만 적용한다.
- 합성 최소값은 원문의 권고2mpy를 정확히 환산한0.0000508m/year이다.
  권고 적용 또는 근거가 있는 미적용을 명시적으로 선택한다.
- §14.3.3은 제품측 일반/국부 선택을 허용하지만 요약 표2.B.1.2는 제품측을 국부로 기재한다.
  본 계산은 해당 상세 절을 따르며 공식 정오표가 있다고 주장하지 않는다.

검증: 신규53개 테스트에서 표 계수, SI/US 구분, 공유 경계, 온도 각 경계의 양옆,
RPB 우선조건, CP 검사 조건, 양면 합성/하한, 통합 식의 독립 산술 앵커,
잘못된 재질·음수·비유한 입력·계산 overflow를 확인했다.
전체1096개 테스트가 통과했으며 독립 검증/현장 인증을 뜻하지 않는다.

미완료: AST 전용 감육 DF, 코팅/라이닝 보호기간의 연결, 시간별 실제 부식 이력,
탱크 전체의 중첩/공통원인 위험, 현장 부식/CP 검증.
기존 바닥 소스·환경피해·재정위험 함수는 외부에서 적합성이 확인된 DF를 계속 입력받는다.
이 부식률을 DF로 직접 대입해서는 안 된다.
