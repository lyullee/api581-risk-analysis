# Annex2.B §12 토양측 부식률

API RP5812016 Part2 Annex2.B Table1.1/1.2(PDF322–323),§12.4와Tables12.2–12.6(PDF417–421)를 사용한다.
식2.B.21,코팅 예제와표는 페이지 이미지로 대조했다. 공개 함수는 api581.api.damage,구현은 soil_corrosion.py다.

## 표와 선택 기준

표의 기본 부식률은.03/.13/.25mm/y와1/5/10mpy다. 정확한 단위 변환값은 서로 다르므로 선택 기준을 필수로 받는다.
기본 프로필은 토양명만으로 자동 선택하지 않는다. 오염·입자·수분도 포함하며 혼합 조건의 임의 보간을 하지 않는다.
적합한 실측 순부식률은 기존 감육 API에 직접 공급할 수 있다. 표 보정에 넣을 기본 부식률의 기준 조건을 확인하고
관측값에 이미 들어 있는 온도·코팅·CP 효과를 이중 적용하지 않아야 한다.

Ωm은 원문Ωcm의1/100이다. 공통1000/2000Ωcm(10/20Ωm)은 양쪽 구간에 걸쳐 있으므로 선택 없이는 실패한다.
500Ωcm은두 번째 구간,10000Ωcm은네 번째 구간으로 원문의 외측 부등호를 따른다.
기본 부식률에 저항률이 이미 포함되었거나 정당하게 생략하는 경우 입력을 다시 주지 않고 생략 근거를 명시한다.

온도 중간 구간은양 끝을 포함한다. SI49/104C와US120/220F는 정확한 환산값이 아니며 같은K에서 분류가 달라질 수 있다.
음극방식 조건은 주어진2016표의 전체 피복·연간 시험·측정 기준·인접 구조물에 따른 분류다.
한 개 전위값만으로 적합성을 판정하지 않는다. 큰/동적 누설전류의 상세 해석은 범위 밖이다.

## 코팅 인자와 인쇄 예제 불일치

나관은FCE1이다. 코팅은 유형 기본값에 적용되는 연령(>20년)·최대온도 이탈·관리 인자를 각각 곱한다.
20년 정확히는 연령 인자를 적용하지 않는다. 해당하지 않는 인자는1이다. CP가 없어도 코팅 인자는 적용한다.
표의 병합된FBE/액상에폭시/아스팔트에나멜/아스팔트매스틱 행은 같은 인자를 공유한다.

원문 식2.B.22는 mill PE tape 예제에서1.5×1.2×3.0×1.5=13.5라고 인쇄했다.
그 수의 실제 곱은8.1이다. API는 독립 인자를 모두 곱한다는 본문·표를 따르며 계산 기준을table_factor_product로 반환한다.
같은 조건에서는 printed_example_reported_factor13.5와 불일치 플래그도 반환한다. 공식 정오표로 단정하지 않는다.

## 감육 연결과 검증

Annex2.B Table1.1의 탄소강·토양 접촉 스크리닝,Table1.2의Local 분류를 사용한다.
soil_thinning_assessment는 비탱크·무클래딩·내압 지배라는 명시적 범위에서 기존 Bayesian 감육 커널로 연결한다.
strength의 시작 두께를 같은 wall-loss 계산에 사용하며,토양 단일 기구의injection/deadleg는1이다.
모니터링과검사 적합성/등급은 외부 입력이다. DF는전체 손상기구 합이나 검사 합격 판정이 아니다.
한 개 상수 부식률 구간이므로 코팅20년 경계나CP/온도 변화 이력을 자동 적분하지 않는다.
AST바닥은 별도의Annex2.B §14/감육식이 필요하며 이번 감육 조합으로 대체하지 않는다.

50개 추가 테스트는 기본/CP/코팅 표,SI/US 값·온도 경계·저항률 구간,
20년 등호·독립 인자·8.1vs13.5·중복 보정·부적합 스크린·수치 범위·독립 감육과통합 결과를 검증한다.
전체1043개 회귀 테스트 통과.
예제는.13mm/y×.83×2×.05×8.1=8.7399e-5m/y,10년/시작10mm의벽손실.087399,
공급한 강도·검사에서 토양 감육 DF.3453447813을 얻었다.
이는 명시한 시험 입력의 재현성 앵커이며 실제 장비 부식률·현재NACE 적합성·수명/검사 허용의 인증이 아니다.
다른 화학 부식률 표·AST바닥·MIC/전기화학 상세 모델·변화 이력·현장 검증은 남아 있다.
