# 산성 사워워터 부식률과 감육

기준: 제공된 API RP581 제3판(2016), Part2 Annex2.B §10,
PDF392–396 및 Annex Table1.1(PDF322).
식2.B.1–2.B.7, SI 기본 부식률·산소 표와 그림10.1을 이미지로 대조했다.
독립 Python API8개 (`api581.api.damage`)를 추가했다.

| 함수 접미사 (`acid_sour_water_`) | 역할 |
|---|---|
| `route` | 자유수·pH·염화물에 따른 대상 부식기구 |
| `base_rate` | pH·온도 기본 부식률40셀 |
| `oxygen_factor` | 산소50ppb 경계 보정 |
| `velocity_factor` | SI/US 구간별 유속 보정 |
| `rate_equation` | CRpH×FO×FV |
| `other_material_rate` | 적격 타재질의 본문 상한 또는 그림 명목값 |
| `assessment` | 적용 가정·재질·위 보정의 통합 |
| `thinning_assessment` | 동일 부식률에서 비AST 감육DF |

분기와 적용성:

- 자유수가 없으면 산성 사워워터 특이 부식률0이며 미계산 중간값은 `None`이다.
  다른 부식/균열이나 총DF가0이라는 뜻이 아니다.
- 상세 본문은 pH<4.5를HCl절, pH>7을알칼리 사워워터절로 보낸다.
  이 경로는 독립 분기 결과로 반환하며 통합 산성 계산은 오류를 반환한다.
  아직 다른 절의 계산을 실행한 것처럼 가장하거나 산성 표를 계속 사용하지 않는다.
- 개요는 pH<7, 상세 본문은 그 외4.5–7 포함이다.
  정확히7은 상세 본문 포함 또는 미분류 정책을 명시적으로 선택한다.
- 그림은 염화물 존재를HCl절로 보내지만 Annex 스크린은<50ppm,
  본문은 유의한 염화물 부재를 가정한다. 그림의 존재 기준 또는 적격<50ppm 해석을 선택한다.
  후자는 실제 농도와 유의하지 않다는 근거가 필요하며50ppm 이상이면HCl로 보낸다.
- 일차 부식성분이H2S이고 NH3·CO₂·CN 등 다른 유의한 부식성분이 없다는 가정을 확인한다.
  혼합물 화학 평형·젖은H2S 균열 메커니즘은 이 일반 부식률 모델과 다르다.
- 본문은 탄소강 중심이며 기본자료 표는 총합금≤6% 저합금강도 포함한다.
  저합금강은 실제 합금분율을 명시해야 하고 범위를 넘으면 계산을 거부한다.

기본 부식률:

SI 표는 pH4.75/5.25/5.75/6.25/6.75와38/52/79/93°C,
US표는 같은pH와100/125/175/200°F이다.
반올림된 온도·mm/year와mpy의 차이를 보존하며 `unit_basis`를 필수 선택한다.
상세 적용 범위4.5–7과 실제 표4.75–6.75의 양 끝 공백은
거부하거나 근거 있는 가장 가까운 끝 행을 명시적으로 선택한다.
끝 행 사용은 보수성/실제값을 보증하지 않으며 별도 표시한다.
온도 밖 외삽은 없고 행 사이 정확값만/이중선형/주변 최대값 정책을 선택한다.
실제 입력은 분리된 수상의 최저pH와 국부 가열까지 반영한 최대 물 온도이다.

보정:

- 산소 표는≤50ppb에서1,>50ppb에서2이다. 본문의 정상<50 표현보다 명시적 표 경계를 따른다.
- SI 유속식은<1.83m/s에서1,1.83–6.10 포함에서0.82v−0.5,>6.10에서5이다.
- US식은<6ft/s에서1,6–20 포함에서0.25v−0.5,>20에서5이다.
  공개 입력은m/s이며 식 기준은 명시한다. 끝점의 불연속이나 SI/US 반올림 차이를 정규화하지 않는다.
- 최종 부식률은 기본값×산소×유속이다. 임의 피팅 배수는 추가하지 않는다.
  고산소/고유속은 국부부식 검토 표지를 반환하며 감육 연결에는 별도 검토 근거가 필요하다.
  원문 기본 분류general과 실제 평가general/local을 별도로 보존한다.
- 온라인 모니터링은 표4.8 sour-water 행을 사용하고 실제 유속을 동일하게 입력한다.
  이 모니터링 표의 저/고유속20ft/s 경계와 산성 부식률식의6ft/s 경계는 서로 다르다.

타재질 본문은 적합한 재질이면0.05mm/year(2mpy)를 초과하지 않는다고 가정하지만
그림은 CR=2mpy라고 표시한다.
본문 상한의 보수적 검토값 또는 그림 명목값을 선택하고, 전자는 상한 사용 표지를 유지한다.
SI0.00005m/year와 정확한2mpy=0.0000508m/year는 별도로 선택한다.
재질 적합성·ClSCC/습윤H2S 균열 등 다른 열화 검토가 없으면 크레딧을 적용하지 않는다.
그림의 독립 타재질 분기에 탄소강 산소·유속 보정을 자동 곱하지 않는다.

신규39개 테스트: 표40셀, pH·중성 경계, 염화물 해석/농도·다른 기구 라우팅,
표 공백·보간, 산소50ppb 양옆·유속6/20ft/s 경계와 불연속,
타재질 상한/명목값, 저합금6% 한계·적용 가정, 국부부식 검토와 독립 감육 커널 일치를 확인했다.
전체1567개 테스트 통과. 현장 적용성 인증이나 원문 전체 구현 완료를 의미하지 않는다.

예제: `examples/acid_sour_water_to_thinning.py`.
알칼리 분기는 `sour_water_assessment`로 연결했다([검증 기록](ALKALINE_SOUR_WATER_VALIDATION.md)).
HCl 분기도 같은 선택 API로 연결했다([검증 기록](HCL_VALIDATION.md)).
미완료: 실제 수상pH·혼합화학·재질 적합성,
국부부식/균열 모델·현장 검증과 모든 손상기구·전체 설비 위험의 자동 통합.
