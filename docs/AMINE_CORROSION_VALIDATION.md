# 아민 부식률과 감육 검증

기준: 제공된 API RP 581 제3판(2016), Part 2 Annex 2.B §8,
Tables 8.1–8.5, Figure 8.1(PDF 382–389쪽), Table 1.2(PDF 323쪽).
표·본문·흐름도를 렌더링하여 확인했다. 독립 공학 인증을 의미하지 않는다.

`api581.api.damage`의 독립 Python API:

| 함수 | 역할 |
|---|---|
| amine_acid_gas_loading | H₂S+CO₂ 몰수 / 활성 아민 몰수 |
| amine_loading_selection | lean/rich 행·부하 공백 정책 |
| amine_contaminant_row | MEA/DEA HSAS와 MDEA 유기산 오염물 행 |
| amine_strength_factor | 아민 농도 보정표 |
| amine_carbon_base_rate | 탄소강 부하·온도·오염물·유속 기본 부식률 |
| amine_stainless_rate | Type 300 스테인리스 부식률 |
| amine_corrosion_assessment | 적격 화학/재질 선택과 기본률×농도 계수 |
| amine_thinning_assessment | 같은 최종률·유속 분류의 감육 DF 연결 |

아민·오염물 농도는 0–1 질량분율, 부하는 mol/mol 활성 아민,
온도 K, 유속 m/s, 부식률 m/year다. 두 산성 가스는 같은 분석 시료 기준이어야 한다.
열화/HSAS를 전체 아민에서 임의로 빼거나 기액 평형을 계산하지 않는다.
MEA·DEA·MDEA 화학 흡수제만 다루며 DIPA나 물리 흡수제로 자동 확장하지 않는다.

탄소강은 두 표군×두 단위×8부하 행×3오염 행×6온도×2유속=1152셀,
스테인리스는 8부하×두 단위=16셀이다. 원문 SI/US 수치와 온도축 차이를 보존한다.
lean<0.1은 6.1m/s 또는 20ft/s, rich 행은 1.5m/s 또는 5ft/s 이하가 낮은 유속이다.
표 경계의 등호는 낮은 유속에 포함된다. 다른 절의 일반 유속 한계로 사용하지 않는다.
부하·온도의 보간은 명시적 정책이며 유속·오염물 범주 사이를 보간하지 않는다.
온도 및 부하>0.7은 외삽하지 않는다.

원문 공백·불일치 처리:

- 탄소강은 lean<0.1 다음에 rich0.15가 나온다. 0.10≤부하<0.15는 기본 거부하고,
  적격 근거로 lean 또는 첫 rich 행을 선택할 때 결과에 표지를 남긴다.
- MDEA 기본 자료는 유기산<500,500–4000,>4000wppm이지만 부식률 표는 HSAS0.5/2.25/4wt%다.
  적격 기본 자료 범주 대응 또는 인쇄 wt% 정확 노드 해석을 명시한다.
  500wppm을 0.5wt%로 바꾸지 않는다. 선택한 인쇄 HSAS 행은 진단 출력이다.
- MEA/DEA의 정확한4wt%는 기본 자료의 중간 범주와 표의4wt% 높은 행 사이 선택이 필요하다.
- 농도 계수의 MEA20–21wt%, DEA30–31wt% 사이 연속값 공백과 MDEA>50wt%는 거부한다.
- 그림의 저합금강 분기와 탄소강 표 제목 차이는 별도 저합금강 적용 근거로 처리한다.
- 개요의 유속 등호 공백과 본문의1.52/6.01m/s, 표의1.5/6.1m/s 차이는
  통합 사용자가 표 유속 분류와 검사 적용성의 근거를 제공하도록 한다.
- 스테인리스 극한 조건의 ‘최대200배’ 설명은 고정 계수나 검증된 상한이 아니다.
  정상 서비스 적격 확인이 없으면 표 적용을 거부한다. 탄소강 농도 계수도 추가하지 않는다.
  스테인리스 표에 없는 부하<0.1은 거부하거나 적격 첫 행 검토값 선택을 표지한다. 보장된 상한을 뜻하지 않는다.

통합 감육은 같은 최종 부식률을 벽두께 손실에 사용한다.
탄소강 계산이 유속 분류를 제공하면 아민 모니터링 행의 분류도 같아야 한다.
스테인리스 표에는 유속 분류가 없어 원문 감육 분류를 임의 추정하지 않는다.
실제 일반/국부 분포와 검사 범위는 별도 적격 근거를 받는다.

신규 테스트1208개 중1168개는 전사 표의 공개 API 조회·단위 변환 확인이다.
`scripts/extract_amine_source_fixture.py`는 같은 원문 추출 절차로 런타임 표와 fixture를 생성한다.
따라서 셀 테스트만으로 전사 정확성이 독립적으로 입증되지는 않는다. 전사는 렌더링 확인에 근거하며,
별도 기대값으로 보간·물리 단위·경계·모델 조합을 검증했다.
`tests/fixtures/amine_source_tables.json`에 PDF SHA-256과 셀별 출처 페이지를 보존한다.
런타임 표는 `_amine_tables.py`에 포함되어 계산 코드 지문의 일부가 된다.

[실행 예제](../examples/amine_to_thinning.py)는 MEA25wt%, HSAS3wt%, 부하0.35,
116°C와2m/s에서 기본1.52mm/year×1.5=2.28mm/year를 확인한다.
20mm 벽두께·2년의 손실분율은0.228이다.
