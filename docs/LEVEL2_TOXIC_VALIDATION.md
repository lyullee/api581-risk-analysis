# Level2 독성 노출·확산 결과 후처리 검증

기준: 제공된 API RP581 제3판(2016), Part3 §5.9(PDF565–568),
Table4.14(PDF531), Annex3.A 식3.A.5(PDF620) 및 기호표(PDF624).
Table4.14의27행과 식3.A.5는 원본 페이지 렌더링으로 대조했다.
이 기록은 소프트웨어 수치 검증이며 독성 모델의 실험 검증·최신 노출 기준 검증을 의미하지 않는다.

## 역사적 표와 계수

`properties.toxic_impact_table`은27종의 A,B,N·IDLH·AEGL3·EPA·ERPG3 값을 조회한다.
methanol과styrene에는 probit 계수가 없어 상수 노출·역산·노출 적분 계산은 오류를 반환한다.
빈 칸은None 또는 AEGL3 사전의 키 없음으로 유지한다. 미제공 값을0으로 바꾸지 않는다.
AEGL3 사전의 키는 노출시간 초의 문자열600,1800,3600이다.

표의 IDLH ammonia10ppm도 원문 그대로 보존한다. 이 데이터를 최신의 직업·응급 노출 기준으로
자동 적용하지 않는다. EPA endpoint의 단위mg/L는 그대로 남기고 ppm으로 변환하지 않는다.
현장 조건·규제 기준·새 기준의 선택은 별도의 근거가 필요하다.

## 상수 노출과 역산

식3.A.5는 `Pr=A+B*ln(C^N*t)`이다. Annex 기호표에 따라 C는ppm, t는초다.
`effects.toxic_species_probit`는 입력을 로그 영역에서 계산하며
`fatality_probability=Phi(Pr-5)`를 반환한다. 농도는 종별 기체 농도0–1e6ppm이다.
농도 또는 시간0이면 유한 probit가 없으므로None, 확률0을 반환한다.

`toxic_species_threshold`는 기본 목표50%(Pr5)의 농도를 역산하며 다른 확률도 명시할 수 있다.
목표는0과1 사이여야 한다. 수학적으로1e6ppm을 넘는 결과는 물리적으로 실현 가능한 농도로
조용히 제한하지 않고 `within_pure_species_limit=False`로 표시한다.

일반 `effects.toxic_probit`는 기존의 사용자 계수·사용자 단위 함수로 유지한다.
그 함수로 다른 출처의 계수를 쓰는 경우 농도·시간 단위를 사용자가 맞춰야 한다.

## 시간별 노출 적분 확장

`effects.toxic_dose_profile`은 상수식의 `C^N*t`를 `integral C(t)^N dt`로 바꾼다.
이는 명시적인 공학 확장으로, 원문에 인쇄된 시간 변화식이라고 주장하지 않는다.
결과의 `method_origin`도 `engineering_transient_extension_of_api581_probit`로 구별한다.

입력은0초에서 시작하는 증가 시각·종별 ppm·보간 방식·입력 근거다.

- `previous`: 각 구간의 왼쪽 농도를 유지한다. 마지막 점은 마지막 구간을 닫는 역할만 한다.
- `linear`: 농도를 선형 보간하고 그 거듭제곱을 해석적으로 적분한다.

선형 구간 평균의 N승과 농도 N승의 구간 적분은 다르다.
예를 들어0→100ppm,60초,N=2의 적분은200,000ppm²·s이며 거듭제곱의 단순 사다리꼴 값300,000과 다르다.
작은 농도 차에서는 `expm1`을 사용한다. 구간들을 로그 합산해 높은 지수·긴 시간의 넘침을 줄인다.
적분량 자체가 float 범위를 벗어나면 `dose_ppm_power_n_s=None`, `dose_representable=False`이지만
유한 `log_dose`·probit·확률·등가 상수 농도는 계속 제공한다.
전체 농도가0인 경우는 표현 불가와 구분해 적분량0을 반환한다.

입력 밖의 농도 꼬리·탈출·차폐·생리적 회복은 모델링하지 않는다.
방출시간과 수용점 노출시간은 다르므로 노출 이력에1시간 상한을 자동으로 적용하지 않는다.

## 방출시간·혼합물 농도 기준

`release.level2_toxic_duration`은 식3.186의
`min(3600,전체 재고/전체 혼합물 유량,검지·차단 최대시간)`을 초로 계산한다.
전체 재고를 독성 성분의 유량으로 나누지 않는다. 무방출·무재고·즉시 차단을 구분한다.
상수 유량 근사이며 과도 감압을 계산하지 않는다.

확산 농도장이 전체 혼합물 농도를 반환하면 식3.189에 따라
`modified_limit=pure_component_limit/toxic_mole_fraction`을 사용한다.
원문 예시100ppm과 몰분율.05의 결과는2000ppm이다. 질량분율을 대신 넣지 않는다.
종별 농도장을 반환하는 엔진에는 이 보정을 다시 적용하지 않는다.
성분이 없는 몰분율0은 기준None·component_present=False다.
보정 기준이1e6ppm을 넘으면 `attainable_in_mixture=False`다.

## 기준 선택·면적 집계

§5.9.2의 우선순위는 probit/LC50, ERPG3/AEGL3/TEEL3, IDLH/EPA endpoint 순이다.
같은 단계의 기준·서로 다른 노출시간은 자동으로 비교 가능한 값이 아니다.
후처리 API는 성분별로 선택한 기준의 근거와 확산 피해면적을 하나씩 받는다.
현재 자동 기준 선택·농도 시간평균·공간 컨투어 추출은 구현하지 않았다.

`consequence.level2_toxic_case`는 §5.9.5에 따라 성분별 면적 중 최댓값을 선택하고
식3.188에 따라 비점화 확률을 한 번 곱한다. 독성 설비 피해면적은0이다.
확산 면적이나 성분별 비점화 가중 면적을 잘못 두 번 곱하지 않도록 입력은 가중 전 면적이다.
동일 성분의 여러 기준을 하나의 사례에 나열하는 방식은 성분 ID 중복 검사로 거부한다.

`level2_toxic_summary`는 네 누출공의 위 결과를 식3.191대로 GFF 가중 평균한다.
누락·중복 누출공과 전체 GFF0을 거부한다. DF 보정 빈도를 이 평균의 GFF 대신 넣지 않는다.

## 검증과 외부 엔진 경계

`tests/test_toxic_level2.py`는27종 조회·가능한25종의 순/역산,
표의 수치·미제공 셀, ppm·초 앵커, 시간 스케일링, 독립 Simpson 적분3조건,
영 노출·비선형 적분·이력 오류·로그 수치 범위·몰분율 예제·성분 최대·확률·GFF를 검증한다.

`examples/toxic_level2_handoff.py`는 명시적으로 가정한 서로 겹치지 않는100m² 셀의
농도 이력을 입력으로 사용한다. 셀 중심의 확률을 분류하는 공간 근사 예제이며 실제 확산 결과가 아니다.
이 예제의 기준값·프로필은 엔진 연동 방법을 보여주기 위한 것으로 현장 예측에 사용할 수 없다.
실제 slabx/slabx-lh2 API와 출력 형상의 매핑·검증 자료는 아직 연결하지 않았다.
추가 엔진 요청/응답 계약은 기존 `dispersion.py`의 초안과 함께 발전시켜야 한다.
