# 고온 황화·나프텐산 부식률 검증

기준: 제공된 API RP 581 제3판(2016), Part 2 Annex 2.B §3,
Tables 3.1–3.10M, Figure 3.1(PDF 331–352쪽), Table 1.2(PDF 323쪽).
18개 표 페이지와 흐름도를 렌더링 확인했다. 독립 공학 인증을 의미하지 않는다.

`api581.api.damage` 독립 Python API:

| 함수 | 역할 |
|---|---|
| sulfidic_material_selection | 재질·316 Mo 함량의 원문 표군 선택 |
| sulfidic_table_axes | 재질별 황/TAN·온도 구간 축 |
| sulfidic_table_rate | 기본 부식률과 명시적 구간/확장 정책 |
| sulfidic_velocity_factor | 100ft/s 고유속 보정과 경계 해석 |
| sulfidic_thinning_classification | 실제 TAN의 일반/국부 분류 |
| sulfidic_corrosion_assessment | 적격 환경·액상·기본률×유속의 통합 평가 |
| sulfidic_thinning_assessment | 동일 최종률의 적격 무클래딩 감육 DF |

황·Mo는 질량분율, TAN은 mgKOH/g 실제 액상유 시료, 온도 K, 유속 m/s,
부식률 m/year다. 전체 원유 평균 TAN을 국부 스트림 TAN으로 사용하지 않는다.
수소가 없는 고온 황화 환경의 적격 확인을 받으며 촉매 H₂S/H₂ 모델로 대체하지 않는다.
나프텐산 영향이 있는 부식률은 원문대로 대략적인 자릿수 추정이며 정밀 물성 상관식이 아니다.

9표군의 SI/US3840셀을 제공한다. 재질별 황/TAN 축을 동일하게 만들지 않았다.
탄소강은 황0.6wt%,5Cr은0.75wt%,다른 대부분은0.8wt% 세 번째 노드를 갖는다.
316/316L/316H는 Mo2.5wt% 이상이면 높은 Mo 군, 미만이면 낮은 군을 사용한다.
Mo가 미상일 때 원문대로 낮은 군을 가정하고 표지를 남긴다. 317은 원문의 높은 Mo 군이다.
미지원 재질·연속 Cr 함량을 임의 보간하지 않는다.

렌더링에서 온도 첫 열은 **≤232°C/450°F**, 마지막은 **>399°C/750°F**다.
문자 추출의 일부 `<` 표기를 렌더링과 구분했다. 두 열은 단일 온도 노드가 아니다.
첫/마지막 구간을 사용할 때 실제 적용성 근거가 필요하고 결과에 구간 사용 표지를 남긴다.
232–260°C/450–500°F 사이의 보간도 첫 구간 경계를 앵커로 삼는 별도 적격 가정이다.
399°C/750°F는 마지막 내부 노드이며 그보다 높은 온도는 즉시 마지막 구간을 사용한다.
열린 구간의 상한 온도를 만들거나750°F에서 그 상한으로 선형 보간하지 않는다.
통합 평가는 명시적 작업 범위를 SI204°C/US400°F 이상으로 제한하며 아래는0 대신 거부한다.

첫 TAN 행은 ≤ 표시가 없는 노드다. 특히 높은 Mo 군은 TAN4–6만 있어
낮은 TAN을 자동 포화시키지 않는다. 기본 거부 또는 적격 첫 행 확장을 선택하고 표지를 보존한다.
최대 TAN 초과·황 함량 표 밖은 외삽하지 않는다.
정확 노드/3축 선형 보간/주변 최대값은 명시적인 수치 정책이다.
12Cr의 일부 온도 증가 시 부식률 감소도 원문 그대로 두고 단조 보정하지 않는다.

유속 보정은30.48m/s(100ft/s) 초과에서5배다.
정확한 경계는 본문 `>`이면1배, 흐름도 `<`이면5배가 되어 명시적 해석과 근거를 받는다.
통합과 감육에서는 이 계수를 한 번만 적용한다.
TAN≤0.5는 원문 일반부식,초과는 국부부식이다.
액상 없는 높은 TAN 경로는 나프텐산 모델의 전제에 맞지 않아 거부한다.
고온 분해 설명으로 마지막 표 열을0 또는 할인율로 바꾸지 않는다.

신규3861개 테스트 중3840개는 전사 셀의 공개 조회·단위 변환 검증이다.
표와 fixture는 같은 `scripts/extract_sulfidic_source_fixture.py` 추출 경로를 공유하므로,
이 테스트만으로 전사 정확성을 독립 입증하지 않는다. 렌더링 확인과 별도 보간·경계·조합 기대값을 사용했다.
OCR의 끊긴 소수와 셀 사이 중점은 렌더링에 따라 정규화했으며 수치 자체를 수정하지 않았다.
fixture에 PDF SHA-256·셀별 페이지를 기록하고 런타임 `_sulfidic_tables.py`는 코드 지문에 포함한다.

[예제](../examples/sulfidic_to_thinning.py):5Cr-0.5Mo,황1.5wt%,TAN1.75,
371°C,31m/s에서0.89mm/year×5=4.45mm/year를 확인한다.
50mm 초기두께·1년의 손실분율은0.089다.
전용 고온 황화/나프텐산 모니터링 행을 쓰며 실제 검사 분포는 별도 적격 확인을 받는다.
