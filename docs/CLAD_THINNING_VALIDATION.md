# 클래딩·용접 오버레이 감육과 설계 최소두께 강도비

기준: 제공된 API RP581 제3판(2016), Part2 §4.5.7, PDF152–155.
식(2.11),(2.14),(2.15),(2.17)을 페이지 이미지로 확인했다.
`api581.api.damage`의 독립 Python 함수5개와 정적 입력·출력 타입을 제공한다.

| 함수 | 계산 |
|---|---|
| `cladding_remaining_life` | 식(2.11)의 기준일 이후 보호층 소진시간 |
| `thinning_clad_wall_loss` | 식(2.13)–(2.15)의 소진 전후 분기·분율 손실 |
| `thinning_design_strength_ratio` | 식(2.17)의 설계/구조 최소두께 강도비 |
| `thinning_clad` | 보호층 감육·선택한 강도비·검사 갱신·최종DF |
| `thinning_unclad_design` | 무클래딩 감육과 식(2.17) 기반DF |

보호층은 모재가 부식하기 전에 먼저 부식한다는 원문 가정을 따른다.
기준일의 잔여 클래딩=max(총 시작두께−원 모재 기준두께,0)이며,
양의 클래딩 부식률로 나누면 소진시간이다.
측정된 총 두께만으로 원 모재 기준두께를 자동 추정하지 않는다.

소진 전 손실은 클래딩 부식률×경과시간이고,
소진 시점 이후에는 잔여 클래딩과 모재 부식률×모재 노출시간의 합이다.
총 시작두께로 나누어 Art를 얻는다. 이미 소진된 경우에는 모재 부식률의 식(2.13)을 사용한다.
총 두께가12mm, 모재 기준두께10mm, 클래딩0.2mm/year, 모재0.5mm/year이면
소진시간10년, 15년 후 클래딩 손실2mm·모재 손실2.5mm·Art0.375이다.

원문 식의 분모 부식률이0인 경우는 별도로 표시한다.
이미 소진되었으면 소진시간0, 온전한 보호층이 부식하지 않으면 소진시간`None`이다.
후자는 모재가 아직 노출되지 않은 해석적 확장이며 원문에 명시된 유한 나눗셈 계산으로
위장하지 않도록 `method_origin`·분기·한계에 표시한다.

강도비 식(2.17)은 S×E/FS×max(tmin,tc)/총 시작두께이다.
외압 또는 구조 하중이 지배할 때 내부 압력만의 식(2.18)을 사용하지 않도록
클래딩 통합 입력에서 `strength.method`로 두 식을 선택한다.
코드 최소두께와 구조 최소두께는 검증된 외부 입력이다. 둘 중 비지배 항을0으로 지정할 수 있지만
둘 다0이면 거부한다. 설계코드 두께·좌굴·FFS나 클래딩의 구조강도 기여를 자동 계산하지 않는다.
S, E, FS의 재질·설계온도 기준은 사용자가 일치시켜야 한다.

통합DF는 기존3개 손상상태·검사 사후확률·기본 COV와 식(2.23)을 재사용한다.
검사횟수·온라인 모니터링·주입점/데드레그 보정은 적합성이 확인된 외부 입력이며,
두께·시간·검사 기준일이 일치해야 한다. AST 전용 건설·유지관리·침하 보정은 적용하지 않는다.
동일 총 시작두께를 벽 손실과 강도비에 사용하며 중복 입력이 다르면 거부한다.

검증: 신규33개 테스트. 소진 전/정확한 소진 시점/소진 직후 연속성,
0부식률, 이미 소진된 경우, 관통 예측 진단, 설계·구조·동일 최소두께,
양쪽 강도비 식의 동등 조건, 모재만 남은 경우 기존 무클래딩 결과와 일치,
독립 함수 조합과 통합 결과 일치, 숫자·적용범위·근거·두께 모순을 확인했다.
전체1189개 테스트 통과. 원문 적용성 전체 검증이나 현장 인증을 의미하지 않는다.

예제 `examples/clad_thinning_to_risk.py`는 계산된DF를 기존4공 GFF·관리계수·피해 입력과 연결한다.
실제 설비는 `damage.combine` 등으로 모든 적용 가능한 손상기구를 포함해야 한다.
예제의 다른 손상기구 배제와 가격·피해는 가상 조건이다.

미완료: 클래딩 재질별 자동 부식률, 실제 두께/검사 이력의 기준일 갱신,
동시 양면 부식·박리·국부 관통/FFS, 코드 최소두께 자동 계산,
현장 검증과 모든 손상기구 통합 적용성 판정.
