# 가성소다 균열 선별과 감수성 연결

근거는 Part2 §6.3/§6.5–6.6, Figure6.2 및 Tables6.2–6.3(PDF172–178쪽)다.
Figure6.2는 PDF178쪽을 렌더링하여 분기와 화살표를 대조했다.
공개 함수는 `api581.api.damage` 아래에 있다.

- `caustic_screening`: 탄소강/저합금강과 모든 농도의 가성소다 노출을 선별한다.
- `caustic_figure_susceptibility`: 자격을 확인한 그래프 영역·농도·열추적·스팀아웃·응력제거·균열 이력으로 감수성을 결정한다.
- `caustic_screened_assessment`: 선별과 감수성을 기존 심각도·검사·경과시간 DF 계산까지 연결한다.

Figure6.1/6.1M의 A/B/C 영역은 실제 최대 금속온도와 국부 NaOH 농도를 고려해 호출자가 판정한다.
이 구현은 그래프 경계를 수치화하거나 입력 영역의 정확성을 자동 확인하지 않는다.
그래프 사용 분기는 NaOH 질량분율0..0.5를 허용하고 정확히0.05는 `<5wt%`의 No분기로 처리한다.
영역A에서5wt% 미만은 열추적 시medium, 열추적 없이 사전 물세척 없는 스팀아웃 시low,
둘 다 없으면none이다.5wt% 이상은 같은 분기에서 각각high/medium/none이다.
영역B/C에서는5wt% 미만medium, 그 이상high다.
실제 국부 농축·업셋·잔류 가성소다를 적절히 고려했다는 근거가 필요하다.

유효 응력제거와 미검출 이력은none으로 분기하지만, 과거 검출·보수 이력은high를 유지한다.
이후 적절한 검사에서 미검출을 확인한 사실만으로 자동 하향하지 않는다.
전문가 재평가 경로에는 적절한 후속 미검출 검사와 전문가 근거를 모두 요구한다.
미보수 균열은 FFS가 필요하므로 `ffs_required`로 거부한다.
열처리 온도·유지시간의 적합성이나 재질의 면역성은 자동 인증하지 않는다.

통합 API는 선별 탈락을 DF0으로 대체하지 않는다.
검사 효과성·적격 경과시간은 §6.6.3 기준으로 별도 확인해야 하며 감육 이력을 그대로 재사용하지 않는다.
기존 Table6.3의 E/500 모호한 셀 및6회 초과 비지원 범위는 유지한다.
API는 감수성 경로·그래프 사용 여부·과거high 유지 여부와 기존 DF 출력을 함께 제공한다.

재현: `python -m pytest tests/test_caustic_screening.py -q`,
`python examples/caustic_screened_assessment.py`.
43개 사례로 재질/노출,24개 그래프 분기,5wt% 경계, 균열 이력·전문가 재평가·FFS,
선별 탈락 및 기존 모호 셀 거부를 검증했다.
예제는영역A/2wt%/열추적으로medium, SVI500, 검사1A의 기본DF25,
2년 경과시 DF약53.58867을 얻는다. 전체 그래프 자동 판정·현장 검증·전체 손상 합성은 남아 있다.

미보수 균열은 재평가 메타데이터가 충돌해도 FFS 오류를 우선 반환한다.
보수 이력이 후속 미검출/응력제거만으로 하향되지 않고, 명시 전문가 재평가 후에만
재분기되는 것을 전체 DF 경로에서도 검증했다.
