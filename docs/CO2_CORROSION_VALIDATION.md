# CO₂ 부식과 감육 연결

기준: 제공된 API RP581 제3판(2016), Part2 Annex2.B §13, PDF423–429.
식(2.B.25)–(2.B.36), 표13.2/13.2M과 그림13.1을 이미지로 확인했다.
습도식은 해당 절의 추출문과 주변 설명을 대조했다.
`api581.api.damage`에 독립 Python 함수13개를 추가했다.

| 함수 접미사 (`co2_`) | 계산 |
|---|---|
| `relative_humidity` | 식2.B.24의 원문 상대습도 근사 |
| `dew_point` | 식2.B.25의 이슬점 근사 |
| `temperature_ph_factor` | 온도·pH 함수98셀 및 명시적 보간 |
| `ph_estimate` | 응축수·Fe++포화·염수3경우 pH 근사 |
| `fugacity` | CO₂ 부분압에서 퓨가시티와 계수 |
| `reynolds` | SI 혼합물 Reynolds수 |
| `friction_factor` | Re>2300의 원문 난류 마찰계수 |
| `shear_stress` | 혼합물 벽 전단응력 |
| `base_rate` | 식2.B.26과 적용 전단응력 상한 |
| `glycol_factor` | 성분 기준을 명시한 글리콜 저감·하한 |
| `rate_adjustment` | 글리콜/억제제 중 작은 저감계수 |
| `corrosion_assessment` | 적격 자유수·pH·유동·보정의 통합 부식률 |
| `thinning_assessment` | 동일 부식률에서 비AST 무클래딩 감육DF |

공개 입력은 K·Pa·m·m/s·kg/m³·Pa·s, 부식률은m/year이다.
원문 상관식 안의 °F·psi·bar·mm/year로 변환한 뒤 계산한다.
퓨가시티식은 전체 압력이 아닌 CO₂ 부분압을 사용한다.
양의 습윤 통합 경로는 탄소강/저합금강,20–140°C, CO₂ 부분압≤4MPa이다.
단독 온도-pH 조회는 인쇄된150°C 행도 보존하지만 통합 적용 범위로 확대하지 않는다.

원문 수식과 경계:

- 표13.2의14온도×7pH=98개 값을 보존한다. pH범위3.5–6.5 밖 외삽/고정은 없다.
  정확한 셀 또는 이중선형 보간을 선택하며, 급격한80–90°C 변화 사이 보간은 별도 근거가 필요하다.
- pH 근사3식은 온도°F와CO₂부분압psi의 상용로그를 사용한다.
  실제 알려진pH가 우선이며 중탄산 완충·고염도·전해질 평형을 자동 모델링하지 않는다.
  원문은 염수 근사에46g/L를 제시하면서 뒤에서45g/L 초과 한계를 경고하므로 해당 모순을 기록한다.
- 퓨가시티식의 분모는 원문T°C+273 또는 명시적 정확한K 해석을 선택한다.
  273을 몰래273.15로 고치지 않는다. 식의 지수 항250bar 제한과 통합 모델의4MPa 범위는 별개다.
- 마찰계수식의 거듭제곱은 인쇄된0.33을 유지하며1/3로 바꾸지 않는다.
  Re≤2300에는 난류식을 적용하지 않는다. 해당 경우는 적격 전단응력을 직접 입력할 수 있다.
  혼합물 물성·홀드업·기상 용해도는 원문도 RBI 범위 밖으로 설명하며 외부 적격 입력이다.
- 기본 부식률은 f(T,pH)×fCO₂^0.62×(S/19)^(0.146+0.0324×fCO₂), 원문bar/mm/year 기준이다.
  지수에는 퓨가시티 자체를 사용하고 log(fCO₂)로 대체하지 않는다.
  적용S는150Pa로 제한하고 요청된 전단응력과 제한 여부를 따로 남긴다.
  S=0에서 원문식의 수치 결과는0이며 정체된 습윤 강재가 안전하다는 판정이 아니다.
- 글리콜 식의G와 기본자료 표의 물 중량%가 달라 성분 기준을 필수 선택한다.
  식의G를 그대로 쓰거나 G=100−물중량%를 사용하며 임의 질량비 정의를 추정하지 않는다.
  계수는max(0.008,((100−G)/100)^1.6)이고G100은 연속 극한과 원문 하한으로 처리한다.
- 억제제 계수는 독립적으로 결정된 효과 근거가 필요하다.
  최종 부식률=기본 부식률×min(글리콜계수,억제제계수)이며 둘을 곱하지 않는다.
  글리콜0.008 하한을 전체 억제제 계수에 임의 적용하지 않는다.

자유수 부재 또는CO₂부재는 CO₂ 특이 부식률만0으로 반환한다.
미계산pH·퓨가시티·전단응력은0으로 조작하지 않고 `None`으로 표시한다.
상대습도식은 원문이 천연가스를 설명하면서 공기의 분자량비0.622를 사용하는 근사이다.
상대습도>1을 보존하며 포화값에 묶지 않는다.
이슬점 식은0<물중량분율≤0.3에서 사용하고, ±10°F 안의 정확도를 보장할 수 없다는 원문 경고를 유지한다.
두 근사만으로 실제 금속의 자유수 부재를 자동 확정하지 않는다.

통합 경로의 자유수·단순 upstream 혼합물·습윤 적합성은 소유자 근거를 요구한다.
이 원시 습윤 커널은 그림13.1의 탄화수소/수분/유속이나13%Cr 경계를 자동 적용하지 않는다.
명시적 정책을 받는 별도 스크리닝 API는 [후속 검증](CO2_SCREENING_VALIDATION.md)에 기록했다.
실제 재질·습윤 상태를 자동 확인하거나 다른 손상기구의 면역을 주장하지 않는다.
감육 연결에서는 같은 부식률·기준두께를 사용하며, CO₂ 부식률0이어도 강도·불확실성·감육0.1 하한 때문에DF가 자동0이 되지 않는다.

신규50개 테스트: 표98셀, 급변 구간·범위, 상대습도/이슬점 단위,
pH3식, 두 온도 분모와 퓨가시티250bar 항, Re/마찰/전단응력,
부식식의 실제 지수·150Pa 상한·0전단응력,
글리콜 성분/끝점·억제제 최소값/근거,
습윤·자유수부재·CO₂부재·적용범위와 독립 감육 커널 일치를 확인했다.
전체1453개 테스트 통과. 현장 또는 원문 전체의 독립 인증을 의미하지 않는다.

실제 억제제 효과/가동률, 가변 공정/부식 이력, 모든 손상기구와 전체 위험의 자동 통합 및 현장 검증.
