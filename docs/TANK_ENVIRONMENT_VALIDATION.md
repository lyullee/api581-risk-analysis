## 계산 순서

비율은 0–1이다. 총량 V에서 방유제 밖은 V·p_leave, 방유제 안은 V·(1−p_leave).
사업장 안은 방유제 밖·p_on_site, 사업장 밖은 나머지·p_off_site, 수계는 최종 나머지다.
세 비율의 합이 1일 필요는 없다. 입력100bbl, .8/.25/.5는 20/20/30/30bbl로 배분된다.

쉘 누출 가중량은 세 누출공의 Σ(V_n·gff_n)/Σ(gff_1..4)다.
파열은 V_4·gff_4/Σ(gff_1..4)다. 누출 분모에도 파열 빈도가 포함된다.
이미 가중한 부피에 GFF를 다시 곱하거나 점화확률을 추가하지 않는다.
정규화는 최대 빈도로 먼저 나누어 양의 유한 입력 합계의 수치 오버플로를 피한다.

바닥 누출은 t_arrival<t_detection일 때 V·(1−t_arrival/t_detection)를 지하수에 배분한다.
나머지는 하부토양이다. 원문의 분모는 탐지시간이며 재고 소진시간으로 대체하지 않는다.
재고가 일찍 소진되는 상황에서도 이 단순식의 물리적 정확성을 보장하지 않는다.
파열은 전체 탱크 재고를 GFF 가중한 뒤 지표 4위치로 배분한다.

양의 거리·0속도는 도달시간 null과 no_finite_arrival을 반환한다.
0거리는 속도와 무관하게 already_at_groundwater와 0일이다.
지하 배분의 탐지시간은 양수여야 하며 정확한 도달/탐지 등호에서는 지하수량0이다.
양수여야 할 계산값의 오버/언더플로는 수치 오류로 처리한다.

바닥 수리비는 누출공별 가중 수리비 합 중 파열 항에만 (D/30.5m)^2를 곱한 뒤 재질계수를 적용한다.
Table4.15 TANKBOTTOM 비용5000/0/0/120000과 재질계수는 기존 financial API로 독립 조회 가능하다.

## 검증과 미완료

34개 추가 테스트로 표18셀, 수동 계산 앵커, 순차 부피 보존, 경계/영 속도,
한 번의 가중·빈도 스케일 불변성, 통화 변환의 부피 불변성, 파열만 지름 보정,
불완전 입력·0분모·비유한 입력을 검사했다. 전체 회귀 테스트856개 통과.
Table6.6과 식3.244–250은 PDF 페이지 이미지로 대조했다.

Table6.6은 추정값이며 명시적 가격연도가 없다. 수리비 표의 USD2001을 임의로 적용하지 않는다.
비용 집계는 같은 통화·기준의 위치별 비용과 비어 있지 않은 cost_basis를 요구한다.
cost_basis는 추적을 위한 호출자 선언이며 경제적 적합성의 자동 인증이 아니다.

탱크 GFF 표 합계 불일치의 내장 선택, 전체 재정 COF(생산손실 포함), 탱크 부품별 최종 위험,
수문학적 플룸·시간별 이송·현장/LH2 검증은 미완료다. 독립 계산 통과가 규격 전체 인증을 뜻하지 않는다.
