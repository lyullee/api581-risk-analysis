# 라이닝 손상계수와 모재 감육 연결

기준: 제공된 API RP581 제3판(2016), Part2 §5, PDF166–171.
표5.4·5.5·5.6과 그림5.1을 이미지로 확인했다.
기존 식(2.24)의 `lining_adjust`를 유지하며 독립 Python API6개를 추가했다.

| 함수 (`api581.api.damage`) | 역할 |
|---|---|
| `lining_effective_age` | 설치일·적격 A/B 검사일에서 선택한 연령 정책 적용 |
| `lining_base_factor` | 표5.4·5.5의9유형×25년, 전체225셀 조회 |
| `lining_condition_factor` | 양호1·보통2·불량10 |
| `lining_monitoring_factor` | 알려진 유효 조기감지·정상 종료 근거가 있으면0.1, 그 외1 |
| `lining_governing_thinning` | 라이닝DF와 모재 감육DF의 최솟값 |
| `lining_assessment` | 이력·기본DF·상태·모니터링·지배 감육의 통합 |

무기 표5.4에는 내식성 스트립 합금·일반/가혹 조건 캐스터블 내화물·유리·산성벽돌·유리섬유가 있다.
유리섬유는 원문 표의 분류를 보존하며 화학적 조성을 자동 판정하지 않는다.
유기 표5.5의 저/중/고 품질은 단순 재질명이 아니라 도포방식·두께·보강 조건을 포함한다.
해당 유형의 적합성은 사용자가 확인해야 한다.

연령 정책과 원문 차이:

- §5.5.3 STEP1은 설치 또는 마지막 A/B 검사 이후 기간을 허용한다.
  §5.5.2는 검사 효과가 현재 계산에 사용되지 않는다고 설명한다.
  구현은 검사횟수/베이지안 가중을 추가하지 않고, STEP1의 연령 기준일 갱신만 명시적으로 처리한다.
- 유기 표5.5는 상단에 마지막 검사 이후 기간, 행에는 사용기간을 표기한다.
  그림5.1도 유기 코팅의 사용기간을 따로 표시한다.
  `step1_installation_or_last_ab`와 `figure51_organic_service_only`를 필수 선택한다.
  두 번째 해석은 유기에만 허용되며 적격 검사가 있어도 설치일 기준을 유지한다.
  공식 정오표가 있다고 주장하지 않는다.
- A/B라는 등급만으로 자동 갱신하지 않는다. 평가기간 내 검사와 해당 라이닝의 적격 근거가 필요하다.
  C/D/E는 갱신할 수 없다. 중복 ID·미래/설치 이전 검사·모순된 근거는 거부한다.
- 날짜만 사용하며 현재 시계를 읽지 않는다. 연 환산365일 또는365.25일을 필수 선택한다.
  운휴기간·교체 이력·시간대 효과를 자동 추정하지 않는다.

표 범위는1–25년이다. 원문에 연속 보간 방법이나0년 행이 없으므로
정확한 행만/선형 보간/상위 행의 보수적 선택을 명시한다.
1년 미만은 거부하거나 근거가 있는 첫해 값 정책을 선택한다.
25년 초과는 일부 열이3000으로 평탄해져도 외삽하지 않는다.

유기 라이닝 통합에는 환경 적합성, 설계온도(스팀아웃 포함), 정상 시공·경화의3가지
원문 가정을 모두 확인해야 한다. 알 수 없거나 거짓인 경우 근거 없는 라이닝 크레딧을 거부한다.
상태는 표5.6의 정성 분류를 사용하며 사진이나 단일 센서값에서 자동 판정하지 않는다.
모니터링0.1은 실제 사용되고 라이닝 열화를 조기에 감지해 정상 종료할 수 있음이 알려진 경우에만 적용한다.
설치된 센서 개수만으로 크레딧을 주지 않으며 여러 방법의 크레딧을 쌓지 않는다.

라이닝DF=기본DF×상태계수×모니터링계수이다.
라이닝 모니터링은 곱하는0.1 계수이며 감육 모니터링의 분모 계수와 다르다.
지배 감육DF=min(모재 감육DF,라이닝DF)이며 라이닝에 감육의0.1 하한을 추가하지 않는다.
모재 감육DF는 실제 §4 계산에 근거한 외부 입력이다.
예제에서 유리5년의9×보통2×유효 모니터링0.1=1.8이며 모재50보다 작아1.8을 선택한다.
이후 다른 기구는 기존 `damage.combine`에서 별도로 포함해야 한다.

신규52개 테스트는 표225셀, 연령 정책·윤년을 포함한 일수 환산,
검사 기준일 갱신·부적격 이력,1년 미만·보간·25년 초과,
상태·모니터링 근거, 최솟값·동일값·0 및0.1보다 작은 값,
유기 가정·분류 모순과 기존 식(2.24) 일치를 확인했다.
전체1287개 테스트 통과. 계산 테스트는 원문 전체나 현장 적용성의 독립 인증을 의미하지 않는다.

호출 예제: `examples/lining_to_governing_damage.py`.
미완료: 실제 라이닝 열화율·시공 적합성·검사 등급의 현장 판정,
자동 모재 손상기구 적용성, 누적 교체·수리/운휴 이력, 모든 손상기구의 자동 위험 연결.
클래딩/용접 오버레이의 순차 두께손실과 라이닝DF는 서로 다른 계산이다.
