# 풀화재 복사 계산의 수식·기하 기준

기준 원문: 제공된 API RP581 제3판2016, PDF550–553쪽 및648쪽.
이 문서는 계산 구현의 검증 기록이며 공식 정오표나 독립 공학 인증이 아니다.

## 두 수직 형상계수 식

`effects.pool_cylinder_view_factor`의 `equation_basis`는 필수다.

- `api581_printed`: 제공된 PDF552쪽 식(3.143)을 그대로 계산한다.
- `geometry_checked`: 같은 원통 기하의 독립 표면 적분과 일치하도록 두 항을 명시적으로 바꾼다.

차이는 다음과 같다. X=L/R, Y=거리/R, θ=수직 기준 화염 기울기이며
A′,B′,C′는 식(3.147)–(3.149)의 값이다.

| 항 | 인쇄된 식 | 기하 적분과 대조한 식 |
|---|---|---|
| 첫 역탄젠트의 인수 | A′(Y−1)/[B′(Y+1)] | sqrt(A′(Y−1)/[B′(Y+1)]) |
| 첫 항의 분자 | X²+(Y+1)²−2Y(1+sinθ) | X²+(Y+1)²−2Y(1+Xsinθ) |

수평 형상계수와 나머지 항은 원문을 유지한다. 두 식은 서로 다른 입력 해시와 결과를 갖는다.
인쇄식의 결과가 음수 또는1을 넘는 등 물리 범위를 벗어나면 진단 조회는 가능하지만 열유속 계산에는 사용하지 않는다.
작은 부동소수점 오차에 대한 물리 범위 판정 허용오차는1e-12다.

## 독립 표면 적분

검증 코드는 `tests/test_pool_fire.py`의 `integrated_view_factors`에 있다.
생산 코드의 폐형식을 호출하거나 계수를 복제하지 않고, 방사 표면을 직접 적분한다.

반지름1로 정규화한 비스듬한 원통 옆면의 점을

`p(t, φ) = (t sinθ + cosφ, sinφ, t cosθ), 0 < t < X`

로 두고 수신점은 `(Y,0,0)`으로 둔다. 원통의 기저·윗면 원은 수평이며 축이 기울어진 기하다.
방향이 있는 면적은 `cross(dp/dφ, dp/dt)`로 구한다. 방사체 가시성,
수직/수평 수신면의 투영, 거리 제곱을 포함한 Lambertian 방사 적분을 중점 구적으로 계산한다.
두 수신면 모두에 대해 가시적 표면 전체가 앞에 있도록 `Y > 1 + X sinθ`를 요구한다.

| X | Y | θ(rad) | 대조한 Fv | 대조한 Fh |
|---|---|---|---|---|
| 3 | 4 | 0 | 0.100013741 | 0.038023207 |
| 3 | 4 | 0.3 | 0.124474927 | 0.059097268 |
| 3 | 5 | 0.7 | 0.108610099 | 0.048313358 |
| 10 | 15 | 0.5 | 0.031882998 | 0.012795760 |

상기 폐형식과 독립 적분의 상대차를2e-5 이내로 검사한다. 구적 분할은 축방향180, 각도방향240이다.
인쇄식은 예를 들어 X=3,Y=4,θ=.3에서 Fv≈.205448896으로, 적분에 부합하는 .124474927과 다르다.
이 비교는 명시한 이상화 기하를 검증하며 연료별 화염 모델이나 실험 열유속을 검증한 것은 아니다.

## 거리 정의

원문 PDF579–580쪽의 xs는 화염 표면에서의 거리로 정의되지만 식(3.146)은 Y=xs/R로 인쇄되어 있다.
반면 원통 기하의 Y는 축에서 잰 거리를 반지름으로 나눈 값이다.
이 축 거리 정의는 [NBSIR88-3755의 기호 정의(S)](https://nvlpubs.nist.gov/nistpubs/Legacy/IR/nbsir88-3755.pdf)와도 대조했다.

따라서 열유속·거리 API의 `distance_convention`도 필수다.

- `printed_surface_ratio`: 원문 그대로 Y=표면거리/R.
- `surface_to_axis`: Y=(표면거리+R)/R.

어느 경우에도 대기 투과 경로는 제공된 표면거리이며, 피해 면적은 식(3.150)–(3.151)의
`pi*(표면거리+R)^2`를 적용한다. 좌표 해석을 자동으로 바꾸지 않는다.

## 임계 거리와 경계 상태

`pool_fire_distance`는 외부 영역에서 열유속이 거리에 따라 감소한다고 가정한 이분법이다.
제공된 최대 거리에서 한계 아래 값이 확인되지 않으면 `unbracketed_threshold`,
허용 반복 내 거리 오차를 만족하지 않으면 `nonconvergent_threshold`를 발생시킨다.

시작점은 기울어진 화염의 바닥 투영 밖이다. 이 위치에서 이미 열유속이 한계 이하이면
`below_limit_at_domain_boundary`를 반환한다. 이때 거리는 보수적인 화염 투영 경계이며
실제 한계 열유속 교차점을 찾았다는 뜻이 아니다. 잔차는None이고 반복 수는0이다.
지면·장애물·화염 직접 접촉을 상세 모델링한 결과로 취급하면 안 된다.

## 단위와 적용 범위

- 물 분압 식(3.141)의 RH는 백분율 기준이다. API의0–1 분율을100배해 사용한다.
- 대기 감쇠 식(3.140)은 kPa·m와 지수−.09를 사용한다. Annex C19의 치수 지수.092와의 차이는 기록했다.
- 투과율이1을 초과하면1로 제한한다. 물 분압0에서는 건조 한계값1을 쓰고 비유한 원값을 반환하지 않는다.
- Thomas 길이 식의 공기 밀도와 무차원 풍속 식의 증기 밀도는 별도 입력이다.
- 바람은 원문의 지상6ft 기준에서 평가된 값이어야 한다. 임의의10m 풍속을 자동 변환하지 않는다.
- 방사출력 W와 표면 방사열 W/m²를 구분하고, 측면+윗면 면적으로 출력 보존을 검사한다.
- 기존 풀 면적 함수의 재고는 사용자가 제공한 액체 질량이다. 원문 식(3.132)의 frac_ro 배치가
  액체 분율 해석과 일치하는지는 별도로 확인해야 하므로 전체 재고에서 액체 질량을 자동 추정하지 않는다.
- 혼합물 연소율은 식(3.130)의 몰 분율 가중이다. 미점화 증발이나 실제 혼합물 물성 추정이 아니다.
- LH2 적용성, 연료별 그을음 차폐, 실험 자료 및 전체 규격 예제 대조는 미완료다.
