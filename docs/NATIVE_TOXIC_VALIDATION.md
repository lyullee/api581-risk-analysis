# 독성 기준 선택과 네이티브 지면 피해

기준: 제공된 API RP5812016 Part3 §5.9.2–5.9.6,식3.186–3.190(PDF565–567),Table4.14(PDF531).
기준 값은 역사적2016 snapshot이며 현재 비상/직업성 노출 지침으로 제시하지 않는다.

## 기준 선택

consequence.select_toxic_criterion은 활성화한 표와 명시적으로 제공한 외부 후보만 고려한다.
후보의 가용성/적용성은 candidate_availability_basis에 선언한다. 현재 문헌/규정 검색을 자동 수행하지 않는다.
표의 probit은 주어진 초 단위 노출에서50% 치사 농도를 역산한다.

우선순위는 probit50/LC50 → ERPG3/AEGL3/TEEL3 → IDLH/EPA endpoint다.
같은 우선순위가 여러 개면 selected_criterion_id를 요구한다. 최대/최소 기준을 자동 선택하지 않는다.
하위 후보를 쓰려면 eligible 상위 후보를 근거와 함께 명시적으로 제외해야 한다.
출력은 선택 기준·단계·근거·eligible/제외/시간 불일치/단위 미변환 사유를 보존한다.

노출시간은 정확히 일치해야 한다. IDLH1800s,ERPG3600s,TEEL900s,
AEGL은API 평가의600/1800/3600s 창을 요구한다. 외부 후보도 같은 창 조건을 지킨다.
LC50는 명시한 시험/노출시간과 근거를 받는다. 시간 외삽이나 자동 보간은 하지 않는다.
표의 EPA mg/L를 ppm으로 임의 변환하지 않는다. 적합한 외부 ppm 후보와 근거가 필요하다.

독립 기준 선택은 순수 기준ppm/독성 몰분율로 혼합물 기준을 한 번 보정한다.
분율0은 성분 없음,수학적 기준이1e6ppm보다 크면 도달 불가로 표시한다. 기준을1e6으로 자르지 않는다.
이 보정 자체가 혼합물 열역학/종별 확산 모델을 계산하는 것은 아니다.

## 실제 네이티브 연결과 노출 해석

dispersion.native_pool_toxic_consequence는 순수 성분의 지면 증발 증기 풀을 SLABx1.0.8에 연결한다.
선택 기준 fluid_id와물성 fluid_id가 같아야 하며 몰분율은1이다. 실제 혼합물 소스는 지원하지 않는다.
유량·면적·물성·대기·공간 격자·기준 적용성은 외부 근거가 있는 입력이다.

식3.186의 소스 지속시간은min(3600s,질량/유량,검지시간)이다.
선택 노출창은 이 소스 지속시간 이하여야 하고,네이티브 평균시간을 그 노출창으로 설정한다.
그보다 짧은 소스는 toxic_exposure_duration_unsupported로 실패한다. 피해0을 뜻하지 않는다.
소스 지속시간·수용점 노출·농도 평균창은 서로 다른 물리량이다.

exposure_model_basis=constant_exposure_equivalent_native_time_average를 필수로 받는다.
이는 일정 노출과 동등하다고 가정하는 평균농도 스크리닝이다.
일반적으로 integral(C(t)^N dt)와 average(C)^N·T는 다르므로 실제 시간이력의 probit dose를 대체했다고 주장하지 않는다.
Native cloud passage/TWA가 각 수용점의 기준 초과 지속시간을 입증하지도 않는다.
실제 노출 이력에는 독립 toxic-dose-profile 등의 별도 처리와 현장 검증이 필요하다.

§5.9.6에 따라 독성 전용 연결은 높이0m를 요구한다. §5.8.6의 플래시화재 전용 연결도0m로 바로잡았다.
일반 centreline/footprint API는 명시한 높이를 계속 지원한다.
지면 높이·노출창이 맞더라도 원시 모델·격자·물성의 현장 적합성을 자동 인증하지 않는다.

Native 평면이 경계에서 잘리면 dispersion_footprint_unusable로 실패한다.
유효한 표본 면적에는 비점화 확률을 한 번만 곱한다. 독성 설비 피해는식3.188 설명의0이다.
사건/GFF를 추가 가중하거나 다성분 최대를 이 단일 성분 연결에 자동 삽입하지 않는다.

## 검증

기본 회귀993개 통과. 추가27개는 기준 우선순위·동급 선택·제외 근거·시간 창·역사적 fallback·몰분율·도달 불가,
중복/불완전 후보·순수 성분·짧은 소스·잘린 면적 차단·평균시간/비점화 가중·지면 조건을 검사한다.
실제 엔진은 scripts/verify_native_toxic.py에서 별도 검증한다.

- Chlorine600s의 독립 probit50 기준55.9445633ppm.
- 직접 native 중심선/횡농도 배열의 정확한 일치.
- 방출/노출/평균창600s와 독립 native 면적 호출의 일치.
- 비점화.8의 한 번 가중,독성 설비0,좁은 격자와짧은 소스 차단.

예제 표본 지면 면적은40664.1437m2,확률 가중 인체 면적은32531.3150m2였다.
이는 명시한 시험 입력·격자·스크리닝 해석의 재현성 앵커이며 실험적 안전면적/치사확률 인증이 아니다.
단순 물성·네이티브 제한·코드 지문/버전은 NATIVE_DISPERSION_VALIDATION.md와같다.
실제 C(t)·짧은 펄스·혼합물/분리 종 확산·criteria 최신성·현장 적용성 검증은 남아 있다.
