# 희염산 부식률과 감육 검증

기준: 제공된 API RP 581 제3판(2016), Part 2 Annex 2.B §2,
Tables 2.1–2.6M, Figure 2.1(PDF 324–330쪽), Table 1.2(PDF 323쪽).
원문 표와 흐름도를 렌더링하여 확인했다. 독립 공학 인증을 의미하지 않는다.

`api581.api.damage`에서 다음 계산을 독립 호출할 수 있다.

| 함수 | 역할 |
|---|---|
| hcl_ph_from_chloride | 무중화제 전제의 염화물→pH 구간표 |
| hcl_chloride_interval_from_ph | pH별 원문 염화물 농도 구간 |
| hcl_ph_rate | 탄소강·304/316/321/347의 pH/온도 부식률 |
| hcl_alloy_rate | 825/20/625/C-276/B-2/400의 농도/온도/산화제 부식률 |
| hcl_assessment | 재질·수상·화학 전제를 포함한 부식률 선택 |
| hcl_thinning_assessment | 동일 부식률의 적격 무클래딩 감육 DF 연결 |

기존 `sour_water_assessment`에도 HCl 정량 모델을 연결했다.
수분/pH 스크린의 분기 결과만으로 희염산 적용성이 입증되지는 않는다.
자식 HCl 모델과 같은 분리 수상이라는 근거가 필요하며, 양쪽에 제공된 pH·염화물도 일치해야 한다.

염화물 농도 입력은 질량분율이다. 예: 0.005 = 0.5wt% = 5000wppm.
HCl 분자 질량분율로 자동 변환하지 않는다. 온도는 K, 부식률은 m/year다.
SI/US 표와 온도축의 인쇄 반올림을 보존하며 보간 방식은 명시적으로 선택한다.
표 밖 pH·온도·농도 외삽은 거부한다.

Table 2.2는 1–2, 3–5wppm처럼 연속 입력 사이 공백이 있다.
2.5wppm 등을 임의 반올림하거나 구간을 확장하여 분류하지 않는다.
pH→염화물 역산은 고유한 농도가 아니므로 구간을 반환한다.
통합 고합금 모델의 역산 경로는 구간 내부의 농도를 명시적으로 선택하고 근거를 제공해야 한다.
근사 변환에는 NH₃·중화 아민·가성 알칼리가 없다는 적격 확인이 필요하다.

스테인리스 표는 일반 부식률에 대한 **10배 피팅 반영값**이다.
같은 보정을 추가로 곱하거나 원문값을 나누어 일반 부식의 확정값으로 사용하지 않는다.
B-2/400은 산화제 있음/없음의 각각의 셀을 조회한다.
예를 들어 400의 0.75wt%, 100°F는 2→10mpy로, 보편적인 4배 보정이 아니다.
400의 1wt%, 100°F, 산화제 없음은 원문 19mpy를 보존한다.
999mpy/25.37mm/year는 원문 수치로 계산하고 해당 셀 사용 표지를 남긴다.
원문에 없는 무한대·누락값 의미를 부여하지 않는다.

신규 테스트 448개에는 별도 원문 추출 fixture의 392개 물리 셀 대조가 포함된다.
탄소강/스테인리스 224셀, 고합금 168셀이며 공유 재질은 별도로 확인했다.
농도 경계·공백·중화제 전제·보간/외삽·역산 선택·산화제·건조·미지원 재질과
공통 수상 일치 및 직접 감육 계산과의 동일성을 검증한다.
`tests/fixtures/hcl_source_tables.json`은 원문 PDF SHA-256과 셀별 출처 페이지를 담는다.

[Python 예제](../examples/hcl_to_thinning.py)는 316, pH 3.25, 79°C에서
1.27mm/year를 사용해 20mm 벽두께·2년의 손실분율 0.127을 검증한다.
예제의 pitting 표지는 이미 반영된 보정을 나타낸다.
