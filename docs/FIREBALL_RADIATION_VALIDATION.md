# 파이어볼 복사 모델의 식·거리·검증 기록

제공된 API RP 581 제3판(2016), Part3 §5.8.4, PDF555–556쪽을 기준으로 한다.
인쇄된 식은 렌더링한 원본 페이지와 대조했다. 이 기록은 실험 검증·독립 공학 인증을 의미하지 않는다.

## 독립 Python API

`api581.api.effects`에서 다음 함수를 제공한다. 각 함수는 타입이 지정된 입력 모델과
`CalculationResult[출력 모델]`을 사용하며 HTTP 서버가 필요하지 않다.

| 함수 | 계산 |
| --- | --- |
| `fireball_mass` | 식3.157: 사용 가능 질량 × 가연성 **질량 분율** |
| `fireball_geometry` | 식3.158–161: 직경·중심 높이·지속시간 |
| `fireball_radiative_fraction` | 식3.163: 파열 압력 기반 방사율 |
| `fireball_emissive_power` | 식3.162: 표면 방사열 W/m² |
| `fireball_view_factor` | 식3.165–166 또는 명시적 구형 기하 해석 |
| `fireball_radiation_flux` | 식3.164: 대기 투과율 × 표면 방사열 × 형상계수 |
| `fireball_distance` | 임계 열유속 거리 및 식3.167–168 면적 |
| `fireball_consequence` | 위 계산을 조합한 인체·설비 거리 및 면적 |

직경·지속시간의 질량 지수는 원문 `.333`, `.167`을 그대로 사용한다.
29,937kg 이하와 초과의 지속시간식을 임의로 연결하거나 보간하지 않는다.
통합 계산의 기본 인체·설비 열유속 기준은 각각12,600,37,800W/m²이다.
LH2 물성을 자동으로 적용하거나 이 상관식의 LH2 적용성을 보증하지 않는다.

## 필수 기하 선택

식3.159는 중심 높이 `H=.75D`를 정의하지만, 인쇄된 식3.166은
`C=sqrt((D/2)^2+(xs/2)^2)`이다. 이를 식3.165에 대입하면
`F=D²/(D²+xs²)`가 되어 중심 높이를 사용하지 않는다.
또한 화염 소스로부터의 거리라는 설명만으로 수평 거리·표면 거리의 관계가 확정되지 않는다.

따라서 `geometry_basis`에는 기본값을 두지 않는다.

| 선택값 | 형상계수 | 대기 감쇠 경로 | 면적 반경 |
| --- | --- | --- | --- |
| `api581_printed` | `D²/(D²+xs²)` | 원문의 명목 거리 `xs` | `xs` |
| `elevated_sphere_maximum` | `(R/hypot(H,x))²`, `R=D/2`, `H=.75D` | `hypot(H,x)-R` | 지면의 수평 거리 `x` |

두 번째 선택은 중심을 향한 수용면 법선에서의 최대 형상계수이다.
고정된 수평 수용면·차폐·화염 접촉을 포함하지 않는다. 별도 기하 해석이며 공인 정오표로 취급하지 않는다.
`model_center_distance_m`는 선택한 모델 내부의 C이고, 인쇄식 선택에서 실제 지면 기하 중심 거리로 해석하면 안 된다.
거리·형상·감쇠 경로는 결과에 노출하고 기하 선택은 입력 해시와 제한사항에도 보존한다.

수증기 투과율은 기존 식3.140 구현을 재사용한다. 명목 경로가0일 때는
상한1을 적용한 극한값을 사용한다. 상수 투과율 모드에서는 사용자가 입력한 상수가0거리에서도 유지된다.

## 독립 기하 대조

`tests/test_fireball.py`는 반경1의 구를 직접 표면 적분한다.
수용점을 구 중심으로부터 거리 `c`의 축상에 놓고, 보이는 구면 캡의 각도 범위
`0 <= theta <= acos(R/c)`에서 Lambert 방출을 적분한다.

적분항은 방출면 법선·수용면 법선·거리 제곱·구면 면적요소로 구성한다:

`2 R² sin(theta) (c cos(theta)-R) (c-R cos(theta)) / (c²+R²-2cR cos(theta))²`.

중점 적분20,000구간을 사용하고 지면 수평 거리0,.5,2,10의 4조건에서
구형 해석과 상대오차2e-8 이내로 대조한다. 인쇄식은 별도로 원문 수치와 비교한다.
이 대조는 코드의 폐형식 계산을 반복한 테스트가 아닌 독립 표면 적분이다.

## 역산과 경계 결과

상수 투과율에서는 두 기하 선택 모두 해석적 임계 거리와 비교한다.
수증기 투과율에서는 역산 지점의 열유속과 바로 안쪽의 열유속을 재계산해 임계값을 감싸는지 확인한다.
거리는 사용자가 지정한 최대 탐색 범위 안에서 이분법으로 계산하며, 허용 오차 이내의
**안전한 상위 구간 끝점**을 반환한다. `flux_residual_w_m2`는 이 점에서 실제 열유속−임계값이다.

- `threshold_solved`: 임계 거리 계산 완료.
- `below_limit_at_origin`: 원점부터 기준 이하이므로 거리·면적0, 잔차는None. 임계값의 해를 찾았다는 뜻이 아니다.
- 통합 결과의 `no_flammable_mass`: 가연성 질량0, 파이어볼 없음.
- 범위 부족·비수렴은 오류로 반환한다. 탐색 범위를 조용히 늘리지 않는다.

원문의 면적식 `pi*거리²`를 사용하며 구 반경을 추가하지 않는다.
형상계수 언더플로·음수 거리·기하 선택 누락·잘못된 대기 입력·방사율1초과도 검증한다.
