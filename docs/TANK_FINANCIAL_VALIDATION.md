# AST 부품 재정피해와 연간 위험

기준은 제공된 API RP581 2016 제3판이다. Part2 Table3.1(PDF147)과 Part3 식3.208(PDF593),
§6.12.2–6.12.3(PDF599–601), 식3.85–3.91(PDF505–506), Tables4.15–4.17(PDF532–534)를 사용한다.
공개 함수는 `api581.api.tank`, 구현은 `src/api581/tank_financial.py`다.

## GFF 총합

| 부품 | small | medium | large | rupture | 인쇄 총합 | 식3.208 총합 |
|---|---:|---:|---:|---:|---:|---:|
| TANKBOTTOM | 7.20e-4 | 0 | 0 | 2.00e-6 | 7.20e-4 | 7.22e-4 |
| COURSE-1-10 | 7.00e-5 | 2.50e-5 | 5.00e-6 | 1.00e-7 | 1.00e-4 | 1.001e-4 |

단위는 모두 failures/year다. 페이지 이미지로 표를 대조했다.
`generic_frequency`는 두 총합과 차이를 반환한다. 계산 총합의 기준은 `hole_sum_eq3_208`다.
이는 원문에서 허용한 합산식이며 표의 공식 정오표라는 주장은 하지 않는다.
기존 비탱크 `frequency.generic`은 별도 계약을 유지한다.
COURSE-1-10을 열 코스 전체 빈도로 곱하지 않으며 개별 쉘 코스를 뜻한다.

## 비용 조합

`component_outage`는 모든 누출공의 GFF로 Table4.17의 정지시간을 가중한다.
바닥 기본값은5/NA/NA/50일, 쉘은2/3/3/14일이다.
NA는 비영 GFF일 때 반드시 사용자 override가 필요하다. 0 GFF의 NA는 기여0이며 출력에서 null을 보존한다.
정지시간에 바닥 파열 수리비의 지름 제곱 보정을 적용하지 않는다.

`bottom_financial_consequence`는 식3.250의 바닥 수리비, 정지×생산손실/일, 지하/지표 환경비용을 합산한다.
§6.12.3에 따라 주변설비·인명 비용은 적용되지 않아0이다.
`shell_financial_consequence`는 쉘 수리비·주변설비·생산손실·인명·환경의 다섯 항목을 합산한다.
설비와 인체 면적은 외부의 AST 가연성/독성 평가에서 이미 GFF 가중한 값이다.
AST에 정의되지 않은 NFNT 면적을 자동 생성하지 않는다.

수리비 표는 USD2001이며 명시한 재질계수·물가계수·통화계수를 적용한다.
쉘 주변설비 정지 상관식에는 주변설비 비용을 동일 계수로 USD2001로 환산해 넣는다.
따라서 입력통화를 바꾸면 금액은 변하지만 정지시간은 변하지 않는다.
환경비용·생산손실·피해면적당 비용·인명 단가는 같은 선언 통화/가격연도여야 한다.
Table6.6에는 가격연도가 없으므로 호출자가 적합성을 확인한 비용과 `cost_basis`를 제공해야 한다.
비어 있지 않은 근거 문자열 검증은 경제적 적합성의 자동 인증이 아니다.

## 연간 위험과 적용 경계

두 `*_risk_assessment`는 부품 하나의 모든 누출공에 같은 외부 DF와 관리계수를 적용한다.
연간 빈도는 Σ(GFF_n·DF·Fms), 연간 재정위험은 이 빈도×이미 GFF 가중한 총 재정피해다.
쉘 면적위험도 같은 빈도×이미 가중한 면적이다. GFF를 다시 면적/비용에 가중하지 않는다.
관리점수500은 Fms1,0은10,1000은0.1이다. 외부 DF0은 피해액을 유지하면서 연간 위험0을 반환한다.
양수 곱이 수치범위를 벗어나면 0 또는 무한대 결과 대신 numerical_failure를 반환한다.
바닥 평가에서 지원하지 않는 물리적 피해면적을0으로 만들어 반환하지 않는다.

22개 새 테스트로 GFF 원문과 합계, NA 보정, 수리·생산·환경 수동 앵커,
쉘5항목·통화/정지시간 불변성·DF/Fms·영 DF·영 면적·수치/출처 검증을 수행했다.
전체 회귀 테스트878개 통과. `examples/tank_financial_risk.py`는 독립 재정피해와 통합 위험의 피해액 일치를 확인한다.

탱크 전체의 손상 적용성·미래 DF·수리/재고에서 소스와 가연성/독성 면적까지 자동 생성하는 평가는 남아 있다.
부품별 외부 DF를 받아 계산하므로 전체 탱크의 코스 중첩, 공통원인 파열, 개별/사회적 위험으로 해석할 수 없다.
원문 형상/누출식의 미해결 해석, 실제 slabx/slabx-lh2 확산 연결과 현장/LH2 검증도 남아 있다.
