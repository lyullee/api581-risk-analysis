# 냉각수 부식률과 감육 연결

기준: 제공된 API RP581 제3판(2016), Part2 Annex2.B §11, PDF397–414.
식(2.B.8)–(2.B.18), 표11.3–11.5와 해수 관련 페이지를 이미지/추출문으로 확인했다.
`api581.api.damage`에 독립 Python 함수11개를 추가했다.

| 함수 접미사 (`cooling_water_`) | 역할 |
|---|---|
| `ph_coefficients` | 표11.3의 C1–C4 |
| `saturation_ph` | 식(2.B.11)의 포화 pH |
| `stability_indices` | LSI·RSI |
| `base_rate` | 염화물·RSI·유속에 따른 기본 부식률 |
| `temperature_factor` | 개방/밀폐 온도 보정 |
| `velocity_factor` | SI/US 유속 보정식 |
| `rate_equation` | 기본 부식률×온도×유속 |
| `seawater_rate` | 해수 일회통과 탄소강 상관식 |
| `coupon_pitting_rate` | 대표 쿠폰 일반 부식률의 명시적5–10배 피팅 추정 |
| `fresh_assessment` | 적용 가정·원문 해석을 명시한 담수 통합 부식률 |
| `thinning_assessment` | 담수 부식률부터 비AST 무클래딩 감육DF |

공개 물리량은 K, m/s, m/year이고 수질 표 단위는 명명된mg/L·ppm을 유지한다.
유속·온도·부식률의 SI/US 쌍은 반올림 차이를 숨기지 않고 선택한다.
본문 적용 범위인 탄소강·pH6.5–9.5, 유효 MIC 제어, 침전물/국부 저유속 부재를 확인한다.
실측 대표 부식률이 있으면 원문은 모델보다 우선할 것을 권고한다.
이번 담수 통합 경로는 억제제 크레딧을 적용하지 않는다.

원문 불일치와 수치 정책:

- 표11.3 C3/C4의20·31mg/L 행에는 계수가 없다. 해당 셀과 그 행을 건너뛰는 보간은 거부한다.
  C4의 첫10.5·12.5mg/L 계수는 실제로10.5·12.5로 인쇄되어 있다.
  이를1.0·1.1로 고치지 않는다. 기본은 모호한 셀 거부이며, 원문값 사용은 별도 근거가 필요하다.
  원시 포화 pH 함수는 이 결과의 음수도 진단용으로 보존하고 물리 범위로 묶지 않는다.
- C2의 °C/°F 표 쌍은 정확히 환산되지 않는다. 기준을 명시한다.
  변환 부동소수점 오차로 정확한 행을 놓치지 않도록 표 좌표에 절대1e-9 이내 값을 맞춘다.
- SI 표11.4M은 두 열에 동일한RSI≤1.8·유속≤2.4 조건을 인쇄한다.
  본문의RSI6·유속2.44m/s 또는 US표RSI6·8ft/s 조건 해석을 명시적으로 선택한다.
  RSI>6 또는 고유속이면 높은 열, 그 외 스케일 보호 열이다. 공식 정오표라고 주장하지 않는다.
  기본 부식률의 SI값과US mpy 환산값도 별도로 보존한다.
- 온도 본문은24°C/75°F를 뺀 ΔT를 사용하라지만 표11.5는 운전온도를 표시한다.
  절대 운전온도 또는 본문의 ΔT 해석을 필수 선택한다.
  표의 끝에서 두 번째 행은 실제로41°C/105°F를 반복하면서 다른 계수를 기재한다.
  기본은 충돌 행/인접 보간/상단 공백을 거부한다.
  근거가 있는 제외 정책만 정상 순서의 행을 사용하며96°C/205°F 행을 임의 생성하지 않는다.
- 표 밖 외삽은 없다. 행 사이 정확값만/선형 보간/두 경계 중 최대값을 선택한다.
  염화물 고농도 영역은 부식률이 감소하므로 상위 농도 행이 항상 보수적이지 않다.
- 일회통과 담수는 원문의엄격한<1000ppm 조건이다. 정확히1000ppm은 자동 분류하지 않는다.

해수 식(2.B.19)/(2.B.20)은 약21°C·용존산소6–8ppm에서 개발되었다.
유속6.1m/s 초과는 원문의 냉각계 가정 밖으로 거부하며,
온도·산소·약품 영향을 임의로 추가 보정하지 않는다.
쿠폰의5–10배 피팅 추정은 대표성 근거와 배수를 요구하는 별도 API이고 모델 부식률에 자동 곱하지 않는다.
흐르는 위치의 쿠폰이 침전물·정체·MIC를 대표한다는 가정을 자동 인정하지 않는다.

감육 연결은 같은 계산 부식률을 §4.5.7의 벽 손실에 사용하고,
강도비 식(2.17)/(2.18), 검사와 조건별 모니터링·배관 보정에 연결한다.
원문 본문은 피팅 지배를 설명하지만 요약 표2.B.1.2는 특정 유속에서 일반부식으로 분류한다.
일반/국부와 검사 범위는 소유자 근거를 입력하며 자동 분류하지 않는다.
AST·클래딩·번들파열·다른 손상기구 전체DF는 이 연결의 범위가 아니다.

검증: 신규81개 테스트. 기본 부식률48셀, 모호한/누락된 pH 셀,
유효 온도행과 SI/US 변환·중복행 거부, 유속·RSI 경계,
해수 두 식·쿠폰 범위, 적용 가정·pH·자료형·수치 오류,
독립 계산과 부식률→감육 통합 결과의 일치를 확인했다.
전체1368개 테스트 통과. 원문 전체나 현장 적용성의 독립 인증을 의미하지 않는다.

예제: `examples/cooling_water_to_thinning.py`.
약품처리·실측 우선 경로는 [후속 검증 기록](COOLING_RATE_SELECTION_VALIDATION.md)의 별도 API로 연결했다.
미완료: 원문 모호 셀의 공식적 해소,
MIC·침전/국부 저유속 모델, 지하수 TKS와 부식률의 수치 연결(원문에도 미제시),
구리·스테인리스 등 타재질 정량 모델, 현장 수질/쿠폰/검사 적합성 검증과 전체 위험 통합.
