# VCE TNT 폭압·거리 검증 기록

기준: 제공된 API RP 581 제3판(2016), Part3 §§5.8.5.3–5.8.5.6,
식3.169–174(PDF557–558쪽), Annex3.B C26–C28(PDF648쪽).
식3.170과 SI 환산표는 원본 페이지 렌더링과 대조했다.
이 기록은 소프트웨어 수치 검증이며 독립 공학 인증이나 LH2 실험 검증을 뜻하지 않는다.

## 공개 Python 함수

| 함수(`api581.api.effects`) | 역할 |
| --- | --- |
| `vce_tnt_equivalence` | 입력 질량·폭발 수율·연소열 → TNT 등가질량 |
| `vce_scaled_distance` | 실제 거리 / TNT 등가질량의 세제곱근 |
| `vce_scaled_overpressure` | 환산 거리의 인쇄 폭압 곡선 |
| `vce_blast_overpressure` | 실제 거리·TNT 등가질량의 측면 입사 과압 |
| `blast_building_probit` | 폭압 → 건물 붕괴 probit·확률 |
| `blast_building_pressure_threshold` | 목표 건물 붕괴 확률 → 압력 |
| `vce_blast_distance` | 임계 압력 → 거리·면적 |
| `vce_blast_consequence` | 입력 질량부터 인체/설비 거리·면적까지 조합 |

모든 함수는 독립 입력·출력 모델을 가지며 계산 결과에는 출처·코드 지문·정규화 입력이 보존된다.
HTTP 실행 경로는 없다.

## 원문 식·단위

식3.170은 `1/ln(R)`의 8차 다항식이다. **다항식 전체에 지수함수를 씌우지 않는다.**
자연로그를 사용한다. 본문은 압력을 bar로 설명하지만 식의 C26=100이 bar→kPa를 수행한다.
공개 결과는 Pa이므로 다항식에100,000을 곱한다.
환산 거리 단위는 `m/kg^(1/3)`이며 C27=1이다. 실제 질량 거듭제곱에는 `math.cbrt`를 사용한다.

예시 환산 거리10에서 과압은 약16,083.41014Pa다.
환산 거리가 같으면 TNT 질량에 관계없이 압력이 같다.
같은 임계 압력의 거리는 질량의1/3승, 면적은2/3승으로 변한다.
출력의 폭압은 측면 입사 **게이지 과압**이다. 반사압·절대압을 계산하지 않는다.

원문의 TNT 연소열4648J/kg과2000Btu/lb는 서로 맞지 않아
`tnt_heat_j_kg`와 `tnt_heat_source`를 계속 필수 입력으로 둔다.
예제의4.648MJ/kg은 명시적인 예시 선택이며 원문을 조용히 수정한 기본값이 아니다.

## 곡선 구간과 검사

원문은 곡선 유효 범위를 제시하지 않는다. R=1에서 특이점이 있고 일부 가까운 거리·먼 거리에서
음수 압력 또는 비단조 곡선이 나타난다. 절댓값·0클램프·추가 지수함수로 이를 감추지 않는다.

`BlastFitDomainInput`에는 다음 세 값이 필수다.

- `minimum_scaled_distance_m_kg13`
- `maximum_scaled_distance_m_kg13`
- `engineering_basis`

최소값>1, 최대값>최소값, 공백이 아닌 근거가 필요하다. 양 끝의 압력이 양수여도
내부에 증가 구간이 있으면 거부한다. 역산은 이 구간 안에서만 이루어지며 임계 압력이
범위 밖이면 `unbracketed_threshold`를 반환한다. 근거 문자열을 받는 것은 그 근거의 타당성을 인증하는 절차가 아니다.

감소성 검사는 `u=1/ln(R)`로 변환해 다항식의 도함수 `Q(u)>0`을 확인한다.
`du/dR<0`이므로 이 조건이 압력 감소를 보장한다.
외향 반올림한 구간 Horner 평가와 이분 분할을 사용한다. 도함수 계수의 곱셈 반올림도 감싼다.
양수임을 확인할 수 없는 구간은 깊이24·방문8192의 제한 안에서 분할하고, 증명하지 못하면 거부한다.
단순한 몇 점의 격자 샘플링으로 단조성을 주장하지 않는다.
계산은 Python 부동소수점 기반이며 형식 검증 도구의 인증을 주장하지 않는다.

예제의1.5–1000은 수학적 동작을 보여주는 구간일 뿐, API가 승인한 유효구간이 아니다.
양수·단조성은 필요한 수학적 조건이며 곡선의 실험적 유효성·설비 적합성을 입증하지 않는다.

## 인체 기준의 의미

식3.172는 `Pr=-23.8+2.92*ln(P_Pa)`이다. C28=1000/kPa를 반영한다.
확률은 `Phi(Pr-5)`이며, 목표 확률의 압력은 정규분포 역누적함수로 구한다.
목표 확률은0과1 사이여야 한다. STEP8.14(PDF564쪽)는 probit5를 지정하고
기호표(PDF578쪽)도 통상5, 확률50%로 설명한다. 통합 VCE의 기본값은 이에 맞춰.5이며
사용자가 다른 기준을 선택할 수 있다. 독립 역산 함수의 목표 확률은 필수 입력이다.

이 확률은 공정 건물의 구조 손상·붕괴에 대한 값이다. 원문이 이를 인체 중상 피해의 대용 기준으로
사용하므로 출력 이름에도 `building_collapse_probability`를 사용한다.
개방 공간의 직접 사망률·폐출혈 모델이나 노출 인원 수를 뜻하지 않는다.
설비 과압 기준의 기본값은 원문34.5kPa=34,500Pa이다.

## 질량·수율·확산 경계

통합 계산은 `mass_basis`와 `yield_engineering_basis`를 필수로 보존한다.
원문은 LFL/UFL 사이 질량을 사용하는 경우 보수적 수율1을 권고하고,
전체 방출 가연성 질량의 경우 통상.03–.19의 수율을 설명한다.
재질명만으로 수율을 자동 지정하지 않는다. 입력 질량·수율의 조합은 사용자가 확정해야 한다.
현재 `flammable_cloud_mass_kg`에는 `mass_basis`로 명시한 질량을 넣는다.
점화 시점의 구름 질량·농도장을 구하는 slabx 계열 확산 계산은 이 모듈에 포함하지 않는다.

TNT 등가질량0이면 `no_explosion`, 거리·면적0이다. 양수 입력이 수치 언더플로로0이 된 경우는
물리적 무폭발로 간주하지 않고 오류를 반환한다.
사건 확률·점화 확률을 피해 면적에 자동으로 곱하지 않는다.

## 검증 근거와 남은 범위

`tests/test_blast.py`에서 다음을 확인한다.

- 80자리 Decimal의 자연로그·직접 항 합산을 이용한 독립 수치 대조6조건.
- 거리·TNT 질량 환산, 압력 불변성 및 거리·면적 질량 스케일링.
- 양 끝이 양수지만 내부가 증가하는 구간을 포함한 잘못된 곡선 구간 거부.
- 건물 붕괴 확률.01,.5,.99의 압력 역산·순산 대조.
- 임계 거리 재구성·안전한 상위 구간 잔차·양 끝점·미괄호·비수렴.
- 통합 계산과 개별 API 일치, 영 질량·영 수율, 언더플로·오버플로 처리.

피해 면적은 `pi*거리²`이다. TNT 점 소스의 근거리 오차, 방호벽·반사·지형·혼잡도·구속도,
충격량·지속시간·TNO/BST 다중 에너지 모델과 LH2 적용성은 미구현 또는 미검증이다.
