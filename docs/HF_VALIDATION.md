# 불산 부식률과 감육 검증

기준: 제공된 API RP 581 제3판(2016), Part 2 Annex 2.B §6,
Tables 6.1–6.3M, Figure 6.1(PDF 374–378쪽), Table 1.2(PDF 323쪽).
표·본문·흐름도 렌더링을 확인했다. 독립 공학 인증을 의미하지 않는다.

`api581.api.damage`의 독립 Python 함수:

| 함수 | 역할 |
|---|---|
| hf_concentration_selection | 농도 적용 범위와 명시적 81wt% 열 확장 |
| hf_carbon_velocity_band | 탄소강 유속 경계 분류 |
| hf_carbon_rate | 탄소강 온도/농도/유속/잔류원소 부식률 |
| hf_alloy400_rate | Alloy 400 온도/농도/산화제 부식률 |
| hf_assessment | HF 노출·재질·원문 분류 정책의 통합 계산 |
| hf_thinning_assessment | 같은 부식률과 HF 모니터링을 사용하는 적격 감육 DF |

농도는 HF-in-water **질량분율**이다. 0.81은 81wt%이며 수분 질량분율이 아니다.
온도 K, 유속 m/s, 부식률 m/year를 사용한다. SI/US 표의 반올림 차이를 보존한다.
탄소강 7온도×2유속×9열×2단위=252셀, Alloy 400은 4온도×2산화제×8열×2단위=128셀이다.
농도 축은 1/2/5/6/63/64/80/81wt%이며 81wt% 탄소강만 low/high residual 두 열이다.
잔류 Cu/Ni/Cr 수치 임계값은 원문에 없어 자격을 갖춘 분류와 근거를 받는다.
81wt% 열이 포함된 보간에서도 이 분류가 필요하다. 관계없는 구간의 잔류 열 입력은 거부한다.

탄소강의 low/high 유속은 SI의 3.05m/s 또는 US의 10ft/s(3.048m/s)를 명시적으로 선택한다.
정확한 경계는 high다. 유속 범주나 산화제 사이를 연속 보간하지 않는다.
온도·농도의 표 사이 계산만 명시적 exact/bilinear/주변최대 정책으로 수행한다.
온도 외삽과 1wt% 미만은 거부한다. 999mpy/25.37mm/year는 원문값과 사용 표지로 보존한다.

원문 불일치와 처리:

- Figure 6.1은 탄소강/Alloy 400의 표 번호를 뒤바꾸어 적었다. 실제 표 제목에 따라 6.2/6.3을 선택한다.
- Table 1.2는 HF를 국부부식으로, 상세 본문은 갈바닉 공격을 제외하면 일반부식으로 설명한다.
  호출자가 분류 정책과 근거를 제공한다. 갈바닉 공격이 있으면 상세 일반부식 정책은 거부한다.
- 본문은 80wt% 이상을 무수 HF와 동등하게 설명하지만 표는 80/81wt% 열이 다르다.
  81wt% 초과는 기본 거부한다. 별도 근거로 81wt% 열을 사용할 수 있으며 확장 표지를 남긴다.
  81이라는 인쇄 헤더를 임의로 ≥81로 바꾸지 않는다.
- 기본 자료 문장의 sulfuric acid 표기는 HF 절 제목·표와 맞지 않는다. HF 자료를 사용하며 공식 정오표로 단정하지 않는다.

무수 HF도 부식을 일으키므로 자유수 없음→0 경로가 없다.
HF 노출 자체가 없다는 적격 확인만 HF 특이 부식률 0으로 연결된다.
탄소강 표의 통합 사용에는 이미 형성된 보호성 불화물 스케일과 안정 운전, 잔류원소 적합성 확인이 필요하다.
초기 노출·스케일 파괴와 갈바닉 가속을 임의 계수로 보정하지 않는다.
갈바닉 공격이 있는 표 경로는 거부하고, 원문 그림이 지시하는 외부 문헌 경로는
`qualified_published_rate`로 재질·온도·농도·유속·출처·적용성 근거를 받아 사용할 수 있다.
해당 출력은 API 581 표 예측과 다른 rate_source를 유지한다.

신규 테스트 401개 중 380개는 원문에서 별도로 추출한 물리 셀의 대조다.
나머지는 경계·단위 차이·명시적 확장·농도/온도 범위·잔류/산화제·본문 분류 정책,
무노출·외부 문헌과 감육 계산의 동일 부식률/모니터링 적용을 검증한다.
`tests/fixtures/hf_source_tables.json`에 PDF SHA-256과 출처 페이지를 기록했다.
원문의 OCR `1 .78`은 렌더링에서 확인한 1.78로만 정규화했다.
프로젝트 루트에서 `python scripts/extract_hf_source_fixture.py`로 fixture를 재추출할 수 있다.

[실행 예제](../examples/hf_to_thinning.py)는 탄소강, 60°C, 81wt%, 낮은 유속과 높은 residual 열의
0.76mm/year를 사용하여 20mm 초기두께·2년의 손실분율 0.076을 확인한다.
같은 예제에 명시적 98wt% 확장과 그 표지를 포함했다.

미완료: 보호피막 성장/제거·희석·응축의 동역학, 별도 HSC/HIC/블리스터와 현장 적용성,
모든 손상기구의 자동 위험 통합. 무노출 0 부식률도 전체 감육 DF=0을 뜻하지 않는다.
