# 감육 온라인 모니터링·주입점·데드레그 보정

기준: 제공된 API RP581 제3판(2016), Part2 §4.5.7 STEP15(1)–(3), PDF155–156,
실제 표4.8(PDF164). 표는 페이지 이미지로 교차 확인했다.
본문은 표4.9를 지칭하지만 실제 표4.9가 아니라 표4.8을 사용한다.

`api581.api.damage`의 독립 Python 함수8개를 추가했다.

| 함수 | 역할 |
|---|---|
| `thinning_monitoring_row` | 기구·재질·유속에서 표 행 선택 |
| `thinning_monitoring_table_factor` | 개별33셀 및 명시적 병용 예외 조회 |
| `thinning_online_monitoring_factor` | 조직적 계획과 근거 확인 후 모니터링 계수 선택 |
| `thinning_injection_point_factor` | 배관 주입/혼합점과 고효율 표적 검사의 보정 |
| `thinning_deadleg_factor` | 데드레그와 고효율 표적 검사의 보정 |
| `thinning_conditional_adjustment` | 기본DF와 조건으로 최종 보정DF |
| `thinning_unclad_qualified` | 무클래딩 감육과 조건별 보정의 통합 |
| `thinning_clad_qualified` | 클래딩 감육과 조건별 모니터링의 통합 |

표 행은 HCl, 고온 황화/나프텐산, 고온H2S/H2, 황산 저/고유속,
HF, sour water 저/고유속, 아민 저/고유속, 기타11개이다.
열은 공정변수·ER프로브·쿠폰3개이며 총33개 계수를 보존한다.
고유속 sour water는 공정변수10/ER2/쿠폰2로 저유속과 다르다.

유속은 공개 입력m/s, 원문ft/s를0.3048로 정확히 환산한다.
황산 저유속 경계는 CS3/SS5/고합금7ft/s, sour water20ft/s이고 경계값은 저유속이다.
아민 행에는 수치 경계가 없으므로 임의 경계를 도입하지 않고 사용자가 저/고유속과 근거를 입력한다.
표의 “Sulfuric Acid” 뒤 “H2S/H2” 표기는 기구명과 화학식이 불일치한다.
이 구현은 명명된 황산 행을 따르며 공식 정오표가 있다고 주장하지 않는다.

표 단일 셀 조회는 계획의 효과를 증명하지 않는다.
최종 모니터링 계수는 조직적 계획이 없으면 설치된 방법 수와 무관하게1이다.
계획에는 기구·관련 변수·전문가가 정한 간격의 적합성 근거가 필요하다.
여러 방법은 합계나 곱이 아니라 최댓값을 사용한다.
HCl과 고유속 황산의 공정변수10은 프로브와 병용하면20이라는 예외가 있다.
이 구현은 두 방법을 모두 선택하고 실제 병용을 확인한 경우에만 적용한다.
표3열의 ER프로브 외 다른 프로브를 자동으로 동등 취급하지 않는다.

표 주1은 경험에 근거한 대체 계수를 허용한다.
`experience_factor`와 근거는 전체 적용계수의 대체이며 추가 가산/곱셈 보너스가 아니다.
기타 센서 방법은 해당 전문 검토 근거로 대체 계수를 입력할 수 있다.
센서가 연결되었다는 사실만으로 계획의 효과를 자동 인정하지 않는다.

주입/혼합점·데드레그 배관 계수는 각각3이며,
해당 국부부식을 다루는 고효율 표적 검사 근거가 있으면 각각1이다.
일반 검사횟수가 많다는 이유로 표적 검사로 인정하지 않는다.
비배관은1이고 배관 특징·검사 크레딧을 동시에 주장하는 모순을 거부한다.
주입점과 데드레그의 구성요소 범위도 일치해야 한다.
클래딩 통합은 비AST 압력용기 범위이므로 두 조건 모두 비배관이어야 한다.

조건 보정은 max(기본DF×FIP×FDL/FOM,0.1)이며 AST 전용 건설/유지관리/침하 계수는1이다.
AST는 별도 전용 API를 계속 사용한다. 무클래딩 통합은 강도비 식(2.17)/(2.18)을 선택하고
클래딩 통합은 기존 소진 전후 계산과 명시적0부식률 확장을 재사용한다.
보정조건의 통합 API는 숫자 보정계수를 중복 입력받지 않는다.

신규46개 테스트로 모든33셀·병용 예외·재질별 유속 경계의 양옆,
아민 근거·부적격 계획·경험 대체·중복 방법 거부·표적 검사 조건,
최종DF 하한·범위 일치·기존 독립 계산과 통합 결과 일치를 확인했다.
전체1235개 테스트 통과. 타입 함수·스키마·패키징 검증을 함께 수행한다.

예제: `examples/thinning_conditions_to_damage.py`.
미완료: 실제 기구 적용성·센서/운전 데이터의 계획 효과 판정,
검사 분류의 현장 검증, 유속/재질 자동 취득, 모든 손상기구의 자동 위험 통합.
