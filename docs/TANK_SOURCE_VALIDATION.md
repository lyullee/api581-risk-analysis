# AST 수리·재고·유출량 검증

기준: 제공된 API RP581 제3판(2016), Part3 §6.1–6.7(PDF592–598),
표6.1M/6.2M/6.5(PDF604–607),Annex C31–C40(PDF648–649).
바닥 유동식·누출공 수·환산상수·유출량/질량 식은 원본 렌더링과 대조했다.

## 독립 Python API

`api581.api.tank`에13개 함수를 제공한다.

| 함수 | 역할 |
| --- | --- |
| `fluid_table` | SI 대표 액체7종의분자량·밀도·점도 |
| `soil_table` | SI 토양8종의인쇄 경계값·공극률 |
| `soil_water_conductivity` | 식3.207의산술 평균·cm/s→m/day |
| `fluid_conductivity` | 식3.205의밀도/점도 제품 보정 |
| `seepage_velocity` | 식3.206의공극률 보정 침투속도 |
| `bottom_hole_count` | 표6.5의지름별 작은 누출공 수 |
| `bottom_inventory` | 전체 원통 재고 |
| `shell_course_inventory` | 코스 하단보다 높은 재고·수두 |
| `shell_flow` | 식3.209의상수 수두 쉘 누출 |
| `bottom_flow` | 식3.210–212의3구간 바닥 누출 |
| `shell_detection_time` | 쉘 지름별 검지시간 |
| `bottom_detection_time` | 기초/RPB별 검지시간 |
| `release_volume` | 재고 제한 누출량·전체 재고 파열량 |

현재는 소스/수리 계층이다. AST 최종 환경·재정 COF·GFF/손상 위험 평가까지 포함하지 않는다.

## 물성·토양·침투 단위

표6.1M의액체 점도는Pa·s,밀도kg/m³,분자량kg/kmol다.
역사적 대표값이며 운전온도 EOS·최신 물성·LH2로자동 매핑하지 않는다.
표6.2M의수리전도도 경계는cm/s다. 대부분의행에서‘lower’값이‘upper’보다 크지만
조회는 인쇄된 라벨과값을 그대로 보존한다.

식3.207은산술 평균이며 C31=864로m/day에환산한다. 원문을 기하평균으로 바꾸지 않는다.
식3.205는제품/물 밀도 비와물/제품 점도 비를 곱한다.
물의기준 밀도·점도는사용자가 공급한다. 온도에따른 자동 물성 보정은 없다.
식3.206은전도도를양수 공극률로 나누어m/day 침투속도를 계산한다.

## 재고와쉘 유동

수직 원통 바닥은 전체 fill volume이다. 쉘 코스 i는하단 높이(i−1)*course_height보다 높은 부분만 재고다.
코스는1부터 시작하고 동일 높이를가정한다. 채움 높이보다 위의코스는음수 재고가 아닌dry0으로표시한다.
이처리는 명시적인 물리적 기하 해석이다. 연결 재고·돔/접시형 탱크는 포함하지 않는다.

원문 C13=6.29bbl/m³를그대로 사용한다. kg는m³×입력 밀도다.
쉘 식3.209는area mm²,g/head SI,C32=.543으로bbl/day를얻는다.
출력m³/s는원문bbl/day를6.29와86400으로 나눈다.
이는정확 Torricelli 환산과비율.543e6/(6.29*86400)의작은 반올림 차이가있다.
계수를임의로정밀값으로교체하지 않는다. Cd는원문의.60–.65,기본.61이다.
상수 수두 가정이며 탱크 수위가낮아지는 과도 배수 모형이아니다.

## 바닥3구간과원문 불일치

바닥 식의지름은mm,수두m,제품 전도도m/day,유량bbl/day다.
RPB가있고액체가존재하면인쇄된수두.0762m를쓴다. 실제액체0이면가상의수두로유량을만들지않는다.
Cqo는원문의.21–1.15,기본.21이다.

- Kh>C34*d²이면식3.210 Bernoulli.
- Kh<=C37*[d^1.8/(Cqo*h^.4)]^(1/.74)이면식3.211 Giraud.
- 나머지는식3.212 전이식이며log는base10이다.

구간 상수와유량 상수는인쇄된SI값을사용한다.
전이식의fractional-power base와m은양수여야한다.
Kh0,빈탱크,누출공0,개수0은log나분수 지수 평가를하지않고0flow를반환한다.

식3.210/211에는누출공 개수n이있지만**식3.212에는없다**.
`transition_hole_basis=api581_printed`는누락을그대로보존하며,
`per_hole_scaled`는명시적으로전이유량에n을곱한다. 후자를공인정오표로주장하지않는다.
적용 배율과per-hole/native rate를출력으로분리한다.

또한C37의SI/US구간 경계는일치하지않는다.
d3.175mm,h10m,Cqo.21에서인쇄SI 경계는5.551875e-7m/day,
인쇄US를환산한경계는1.692645e-7m/day로비율.304878이다.
이를단순 반올림오차로보지않고미해결로기록한다.
API는SI구간을일관되게쓰며US경계와섞지않는다.

## 누출공 수와검지 경계

표6.5는`max(1,nint((D/30.5)^2))`를사용한다.
nint는양수.5에서올림하는최근접 정수로Python의짝수 반올림과다르다.
중/대 누출공 수는0이다. 표 범위30.5–91.4m 밖 계산은외삽 플래그를남기며유효성을주장하지않는다.

쉘 검지시간은원문3.17mm와괄호.125inch=3.175mm가달라필수기준을받는다.
`printed_3_17_mm`또는`inch_0_125`의경계이하7일,초과1일이다.
명목 작은공3.175mm에서이선택이1일/7일을바꾼다.

바닥의concrete/asphalt7일,RPB30일,기타360일조건은기초와RPB가함께있으면중복된다.
이때`foundation_priority`또는`barrier_priority`를명시해야한다.
이를일반압력설비의검지·차단 감소계수로대체하지않는다.

## 유출량과질량 표기

누출시간은재고bbl/rate와검지시간의최소다. 누출량은rate×시간과재고의최소다.
파열은전체가용재고를사용하며시간을발명하지않고None을반환한다.
AST의원문 방출분류는§6.5에따라continuous로남긴다. 파열을자동으로pressure-vessel의instantaneous로바꾸지않는다.

식3.225/227은**mass=Bbl**로인쇄되어밀도·단위환산이없다.
API는그숫자를`printed_mass_index`로보존한다.
`released_mass_kg`는부피m³×밀도로계산하며식3.218/221에따른명시적차원해석이다.
둘을같은kg값으로표시하거나이해석을공인정오표로주장하지않는다.

## 검증과후속 범위

`tests/test_tank_sources.py`는유체7/토양8행,단위평균·제품/침투 보정,
누출공수·코스하단/건조 재고·쉘단위·세바닥분기·구간등호·RPB·전이식개수,
검지시간/중복조건·유출상한·질량지수와SI질량을검증한다.
바닥3유량식은같은분기로선택되는경계에서먼입력에서인쇄US유량과대조했다.
이대조가C37의구간선택까지맞는다는뜻은아니다.

`examples/tank_sources.py`는물성/토양→제품 전도도→침투→바닥/쉘rate·재고→유출량을실행한다.
물의기준 물성·기초·전이식·검지 경계 선택은예제 가정이다.
탱크 GFF합계·환경/지하수 피해·재정위험·동적배수·현장/LH2 적용성은남아있다.
